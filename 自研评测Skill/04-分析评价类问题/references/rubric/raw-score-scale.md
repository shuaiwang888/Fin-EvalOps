# 原始分量表

每个维度按六档锚定值（0/20/40/60/80/100）打分。

- `100`：完美满足维度要求，无任何可挑剔之处；能抓住本题关键投资判断
- `80`：很好地满足维度要求，仅有极轻微不足；不影响主体判断
- `60`：基本满足维度要求，有可改进的明显不足；用户仍需自行补关键判断
- `40`：部分满足维度要求但关键需求缺失或偏差较大或关键证据
- `20`：仅触及维度边角，遗漏了核心需求；只提供泛泛模板或错误方向
- `0`：未完成该维度，或直接违反用户明确要求

加权公式：`加权分 = 原始分 / 100 × 动态权重`。

动态权重来自步骤 0 的 `weight_assignment`，`not_applicable` 维度权重为 0，不参与评分。

所有活跃维度（`relevant` + `supplementary`）的加权分之和即为 `absolute_score_pre_cap`，由调用方代码计算。
