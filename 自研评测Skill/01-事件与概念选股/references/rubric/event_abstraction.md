# `event_abstraction` 事件抽象度（建议权重 15）

判断答案是否提取了事件背后的真实驱动因素，而非复述表面新闻。

关注点：
- 识别了真正的催化剂、瓶颈、政策杠杆或地缘驱动因素
- 将嘈杂的新闻压缩为可投资的主题
- 对概念题完成"逻辑脱水"：提炼需求爆发、供给收缩、国产替代、价格上涨、客户认证、资本开支、政策投向等可投资驱动
- 对海外映射题拆出海外标杆上涨或强势的真实原因，再判断 A 股是否具备相同驱动
- 对短期新闻/事件题标明事件发生时间、来源层级、事件性质、持续性和后续验证点；不能只写"最近发生了一些事件"
- 对概念交集题说明交集背后的真实产业逻辑，而不是把两个概念标签机械相加

常见失败模式：
- 新闻转述，没有提取驱动因素
- 概念堆砌，没有解释什么真正影响盈利、供给、定价或情绪（注：概念堆砌如果缺少驱动因素归本维度；如果缺少受益链条映射归 `industry_mapping`）
- 只复述题干或研报观点，没有说明事件影响程度、发酵阶段、短期扰动与长期供需变化的区别
- 先有股票名单再硬凑事件链条，事件和标的之间缺少明显承接
- 把概念命中数量、概念标签或主题交集当成事件逻辑本身，未说明为什么这些主题会共振

## 适用性判断

- **relevant**: 题目涉及具体事件（战争、政策发布、产品上市、供给冲击、地缘冲突、公司事件）或概念主题驱动的选股/分析
- **supplementary**: 题目涉及行业板块、产业链、产品应用、客户供货或海外映射但无具体事件催化
- **not_applicable**: 纯条件筛选（均线、涨幅排名、财务指标筛选）无事件/主题推理层
