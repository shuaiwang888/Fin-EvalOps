# Raw Score 六档标准

所有维度只输出 `raw_score`（六档：0/20/40/60/80/100），调用方负责加权和最终分计算。

| raw_score | 含义 |
|---|---|
| 0 | 完全失败；答非所问、事实/规则硬错、对象错位或无法使用。 |
| 20 | 严重不足；触及相关主题，但核心任务、规则、上下文或证据失败。 |
| 40 | 部分可用；方向有相关性，但关键变量、口径、承接或行动闭环缺失。 |
| 60 | 基本合格；主要需求满足，但仍有明显可改进点。 |
| 80 | 良好；覆盖主要显性和隐性需求，只有轻微不足。 |
| 100 | 优秀；意图、澄清、规则、证据、行动方案和后续引导形成闭环。 |

不要输出小数。不要把链路中"想到了"但最终答案没说出的内容计入最终答案维度；链路只用于 `tool_usage`、`latency_efficiency` 和根因归因。
