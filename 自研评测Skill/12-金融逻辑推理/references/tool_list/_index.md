# 工具使用参考

| 工具 | 合理用途 | 推理风险 |
|---|---|---|
| Search | 查热点、市场情绪、行业催化、分析文章 | 只搜常规公告导致驱动缺失 |
| FinQuery | 查估值、财务、行情、资金、业务数据 | 静态指标堆砌，不形成逻辑 |
| AccessingFullText | 查公告、研报、年报业务占比 | 摘录不综合 |
| BackTest | 验证策略或条件历史表现 | 用历史表现承诺未来 |
| Forecast | 做情景预测辅助 | 给过度确定结论 |
| CodeInterpreter | 多股指标比较和排序 | 表格替代推理 |

评分重点：
- 工具是否覆盖题目所需的驱动、基本面、资金、技术和风险。
- 工具结果是否被综合成明确逻辑链。
- 是否避免单一工具视角压倒投资判断。
