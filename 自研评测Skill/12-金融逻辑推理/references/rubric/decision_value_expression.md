# `decision_value_expression` 决策价值表达

评估答案是否有可执行的决策参考价值。

| 分数 | 标准 |
|---|---|
| 100 | 决策价值极高，判断明确、可执行、有验证路径 |
| 80 | 决策参考清晰，有可执行的判断和建议 |
| 60 | 给出了基本判断但可执行细节不足 |
| 40 | 有基本方向但缺少可执行的具体判断 |
| 20 | 表达模糊，用户无法基于答案做任何判断 |
| 0 | 答案无任何决策参考价值 |

## 常见失败模式

- 结论是"建议关注"但没说关注什么、什么时候验证
- 给了大量数据但没有提炼成判断
- 答案方向正确但用户看完不知道怎么操作

## 适用性判断

始终 supplementary；操作建议题 relevant。
