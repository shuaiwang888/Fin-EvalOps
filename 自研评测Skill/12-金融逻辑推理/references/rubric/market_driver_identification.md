# `market_driver_identification` 市场驱动识别

评估是否准确识别热点、催化或价格驱动因素。

| 分数 | 标准 |
|---|---|
| 100 | 市场驱动完美识别，所有核心催化和情绪因素均被覆盖 |
| 80 | 市场驱动识别准确，热点和催化分析到位 |
| 60 | 主要驱动基本识别，但个别催化因素分析不够深入 |
| 40 | 识别到部分驱动但主驱动缺失或方向偏差 |
| 20 | 关键市场驱动遗漏，导致分析方向根本错误 |
| 0 | 完全未识别任何市场驱动因素 |

## 常见失败模式

- 明天涨停只看连板，不找市场热点和题材情绪
- 热点短线题只看静态指标不看催化
- 把宽泛的"政策利好"当作驱动，没有具体催化分析

## 适用性判断

短线、热点、走势、板块题 relevant；纯基本面题 supplementary。
