# `data_asof_freshness` 数据时点新鲜度

核验数据日期，防止旧数据冒充当前事实。

| 分数 | 标准 |
|---|---|
| 100 | 所有数据时点精确标注，as-of透明，替代数据使用有充分理由 |
| 80 | 明确数据as-of，若无最新数据说明使用上一交易日/最新可得数据的原因 |
| 60 | 数据时点基本正确但as-of标注不够完整 |
| 40 | 使用的数据大致可接受但as-of说明不足 |
| 20 | 数据明显过时但答案未做任何说明 |
| 0 | 把上一交易日或旧财报数据当成今天/最新事实，没有任何提示 |

## 适用性

涉及今天为什么涨跌、最新价、最新公告、最近数据、当前行情、近期表现。
