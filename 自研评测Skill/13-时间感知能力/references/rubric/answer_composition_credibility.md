# `answer_composition_credibility` 答案可信表达

最终答案是否让用户清楚理解时间口径和可信边界。

| 分数 | 标准 |
|---|---|
| 100 | 时间口径和可信边界完美呈现，用户一眼可判断数据适用范围 |
| 80 | 日期、市场、数据时点、限制和替代口径表达清楚，不模板化 |
| 60 | 表达基本清晰但时间口径和限制可更明确 |
| 40 | 主结论可读但时间边界散乱或不够突出 |
| 20 | 表达混乱，时间边界模糊或容易误解 |
| 0 | 模板化套话、堆行情指标，掩盖关键时间错误 |

## 适用性

所有时间感知题。表达维度通常为5-10分。
