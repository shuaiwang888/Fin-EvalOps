# `market_calendar_status` 交易日历状态

判断对应市场、品种或证券在目标日期是否交易。

| 分数 | 标准 |
|---|---|
| 100 | 交易日历完美判断，所有市场状态、交易时段和跨市场差异均正确 |
| 80 | 正确判断目标市场交易状态，区分休市、半日市、盘中/盘后和跨市场差异；目标日期休市时不得默认给出下一交易日的交易结论，除非用户明确要求 |
| 60 | 交易日历判断基本正确但跨市场差异说明不足 |
| 40 | 知道可能涉及交易日历但仅泛泛提示，未落实到目标日期/市场 |
| 20 | 交易日历判断严重错误，张冠李戴不同市场日历 |
| 0 | 休市日仍给出当日交易结论 |

## 适用性

涉及开盘、走势、今天涨跌、港股/A股/美股/期货/外汇/贵金属、节假日、非交易日。
