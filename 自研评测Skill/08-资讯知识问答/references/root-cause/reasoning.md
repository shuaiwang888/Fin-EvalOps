# L1: reasoning

系统拿到信息后没有推导出正确主线、影响链或投资映射。

| L2 | 说明 | 常见受影响维度 |
|---|---|---|
| `core_signal_missed` | 没抓到最能解释市场反应的主因 | `core_signal_extraction` |
| `weak_causal_chain` | 事件到行业/标的/市场反应之间链条断裂 | `information_integration`, `investment_mapping` |
| `mapping_too_broad` | 标的映射过宽，缺少直接/间接、核心/边缘分层 | `investment_mapping` |
| `comparison_not_converged` | 横向比较维度不一致或没有最终判断 | `information_integration` |
| `progress_stage_confused` | 混淆送样、测试、定点、量产、投产、公告规划等阶段 | `timeliness_fact_boundary`, `fact_evidence_quality` |
| `template_reasoning` | 套固定模板，未根据题目真实催化剂推理 | `core_signal_extraction`, `intent_fulfillment` |
