# `constraint_coverage` 约束覆盖

评估时间、范围、对象、排除条件等约束是否被覆盖。

| 分数 | 标准 |
|---|---|
| 100 | 所有显式和隐式约束完美覆盖，无任何遗漏 |
| 80 | 约束覆盖全面，所有显式条件均被处理 |
| 60 | 主要约束基本覆盖，但个别边界条件不够精确 |
| 40 | 部分约束被覆盖但关键限制条件遗漏 |
| 20 | 关键约束被忽略，导致答案严重偏离用户要求 |
| 0 | 完全忽略所有用户约束条件 |

## 常见失败模式

- 用户要求"截止某时点"但答案包含该时点之后数据
- 用户要求"只看某范围"但答案超出范围
- 用户要求"不要某类"但答案包含该类

## 适用性判断

用户有时间、范围、对象、排除条件时 relevant；否则 supplementary。
