# `task_type_alignment` 任务类型对齐

评估原因、定义、比较、排序、建议等任务类型是否对齐。始终考察。

| 分数 | 标准 |
|---|---|
| 100 | 任务类型完美对齐，所有子任务和输出形态精确匹配 |
| 80 | 任务类型对齐准确，输出形态匹配用户需求 |
| 60 | 任务类型基本正确，但部分子任务执行有偏差 |
| 40 | 任务类型大致相关但输出形态与用户需求明显不匹配 |
| 20 | 任务类型根本错误，如问定义却答行情查询 |
| 0 | 答案任务类型与用户要求完全相反 |

## 常见失败模式

- 问原因，只回答上涨事实
- 问定义，只给指数、行情或查询结果
- 问比较，只分别介绍不比较
- 用户指定对象，答案覆盖了泛概念但遗漏对象

## 适用性判断

始终 relevant。所有题目均考察任务类型是否对齐。
