# `necessary_information_completeness` 必要信息完整度

评估必要证据和信息是否完整支撑答案。

| 分数 | 标准 |
|---|---|
| 100 | 信息完美完整，所有必要证据和细节均到位 |
| 80 | 必要信息完整，证据充分支撑结论 |
| 60 | 必要信息基本齐全，但个别支撑点可补充 |
| 40 | 有部分证据但关键信息缺失，结论不牢靠 |
| 20 | 必要信息严重缺失，答案无法成立 |
| 0 | 完全没有支撑答案的必要信息 |

## 常见失败模式

- 问原因只给一个数据点不做交叉验证
- 比较题缺少某些方面的对比数据
- 概念定义缺少关键要素

## 适用性判断

始终 supplementary；主指令需要证据链时 relevant。
