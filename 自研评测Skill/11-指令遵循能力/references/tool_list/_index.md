# 工具使用参考

| 工具 | 合理用途 | 指令遵循风险 |
|---|---|---|
| Search | 查原因、政策、事件、定义背景 | 只贴新闻不回答原因 |
| FinQuery | 查行情、板块、个股、指标 | 把查询结果误当最终答案 |
| AccessingFullText | 查公告、研报、基金文件 | 摘录过多导致主问被淹没 |
| Forecast | 辅助建议和情景判断 | 用户问定义/原因时滥用预测 |
| CodeInterpreter | 计算或整理多项约束 | 用表格替代直接回答 |

评分重点：工具是否围绕用户主指令设计，工具结果是否被转化成用户要求的答案类型。
