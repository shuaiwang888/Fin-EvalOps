# `time_inference` 时间推理正确性（权重 15）

判断答案中的时间推理是否正确——自然语言时间表达是否被精确解析为实际交易日期和时间范围。

关注点：
- 交易日判断：特定日期是否为交易日（不能将交易日幻觉为非交易日）
- 节假日倒推："节前N日"是否正确推算为N个交易日（而非N个日历日或错误的日历区间）
- 时间范围定位："过去5年"、"上市以来"、"2026年一季度"等时间范围的起止点是否正确
- 分时精度：要求具体时间点（如"13点11分"）时是否使用了分时数据而非日线数据

常见失败模式：
- 幻觉交易日状态：错误声称某交易日"不是交易日"，降低用户信任
- 日历日与交易日混淆："五一节前5个交易日"推算为日历日前5天而非交易日前5天
- 年报披露日期等结构化事件日期提取错误，导致后续次日涨跌幅计算的锚定点偏移
- 时间范围截断：长期统计仅覆盖最近数据，未达到用户要求的时间跨度

## 适用性判断

- **relevant**: 题目涉及具体日期判断（交易日/非交易日）、节假日倒推（"节前N日"）、时间范围定位（"过去5年"、"上市以来"、"某年某月某日"）
- **supplementary**: 题目无明确时间推理要求但仍需确保时间锚点准确
