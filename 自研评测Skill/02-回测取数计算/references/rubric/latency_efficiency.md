# `latency_efficiency` 响应耗时与执行效率（权重 5）

判断答案链路是否在复杂取数计算任务中保持可接受的执行效率。此维度服务专家评论中的"效能与正确度双输"风险，但不能替代正确性评分。

评分前提：
- 仅在输入材料包含耗时、时间戳、工具调用时长或可推断的响应耗时时评分。
- 如果完全没有耗时证据，给中性分 `60`，并在 evidence 中说明"缺少耗时证据"。

关注点：
- 大规模统计效率：行业十年概率、全市场条件选股等任务是否避免明显低效的全量反复查询
- 多步回测效率：是否先规划必要中间结果，再批量或结构化取数，避免无效重试
- 正确性优先：不能为了快而省略必要样本、时间范围或核验步骤
- 结果可用性：耗时显著过长且结果仍错误时，应同时扣本维度和对应正确性维度

常见失败模式：
- 耗时远高于同类任务且输出错误或不可验证，如长时间取数后给出方向颠倒的行业概率
- 多次重复调用同一类查询但没有扩大覆盖、纠错或交叉验证收益
- 为追求速度只取最近样本，导致长期统计样本不足
- 因工具失败反复空转，最终强行输出无依据结论

## 适用性判断

- **relevant**: 题目涉及大规模统计、全市场筛选、多步回测等耗时任务，且输入材料包含耗时证据
- **supplementary**: 题目为简单取数，或输入材料无耗时证据（无耗时证据时给中性分 60）
- **not_applicable**: 题目极其简单（单指标查询），耗时无意义
