# `calculation_accuracy` 计算准确性（权重 15）

判断答案中的财务公式选择和算术运算是否正确。

关注点：
- 公式正确性：使用的财务公式是否为专业标准（如毛利率=(营收-营业成本)/营收、区间涨跌幅=(期末价-期初价)/期初价）
- 复权方式：涉及分红再投资时是否使用前复权收盘价（而非未复权价）
- 算术准确性：加减乘除、求和、求平均、百分比计算等是否有误
- 概率计算：分母（总样本数）和分子（符合条件数）是否正确

常见失败模式：
- 公式选择错误：使用未复权价计算分红再投资收益，导致方向和量级均错误
- 系统性算术错误：期间费用率计算时加法出错，虽然每个单值正确但汇总出错
- 概率分母错误：将涨停后高开次数除以错误的总次数，概率统计失真

> **边界说明**：基础数据取错（如营业成本取错字段）导致后续衍生计算全部错误，属于 `data_retrieval_accuracy` 的范畴（见 evidence/wrong-data-value）。`calculation_accuracy` 仅负责公式选择和算术运算是否正确——即使基础数据正确，公式或运算本身出错才归本维度。

## 适用性判断

- **relevant**: 题目涉及计算任务（涨跌幅、概率、盈亏、毛利率、费用率等衍生指标）
- **supplementary**: 题目以数据提取为主，计算为辅
