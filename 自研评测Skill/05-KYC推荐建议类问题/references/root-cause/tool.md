# L1: `tool`

用于归因工具选择、工具输入、工具输出读取或工具效率问题。

常见 L2：
- `missing-tool-call`：明确需要行情、估值、基金、历史阶段或新闻数据，却没有调用合适工具。
- `wrong-tool-choice`：结构化金融数据用搜索替代，或非结构化新闻用错误工具。
- `poor-tool-input`：工具输入没有包含关键标的、时间窗口、用户约束或比较对象。
- `tool-output-misread`：误读工具输出，或最终答案与工具结果冲突。
- `low-value-tool-latency`：大量工具调用和长耗时没有带来推荐质量提升。

证据要求：
- 引用 `chain.tools[M]` 的工具名、输入或输出摘要。
- 说明工具问题如何影响具体评分维度。
