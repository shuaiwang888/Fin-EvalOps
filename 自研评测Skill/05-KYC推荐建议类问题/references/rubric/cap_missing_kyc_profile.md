# 封顶规则：`missing_kyc_profile`

## 触发条件

05 类 KYC 推荐建议问题中，模型理当使用用户 KYC 数据，但链路和最终答案没有体现任何 KYC 数据使用，导致回答按通用推荐处理。典型表现：
- 没有主动读取、调用、检索或引用用户 KYC 数据
- 未使用画像工具、画像存储、历史 `context`、当前问题自述或其他可见画像来源中的风险偏好、投资期限、资金目标、持仓、交易经验、投资风格
- 未说明用户画像依据不足
- 未给分层假设、适用人群、低风险边界或必要追问
- 直接输出通用标的、热门方向、模板组合或普通市场观点
- 可见资料已有画像或历史投资记录，最终答案仍声称“未提供风险偏好/无法判断”，并按通用推荐处理

## 分数上限

`score_ceiling = 60`

## 不触发条件

- 链路已主动获取或使用用户 KYC 数据，并且最终答案能看出推荐结论受 KYC 约束。
- 链路未取到可用 KYC，但最终答案明确说明画像依据不足，并给出稳健分层建议或追问。此时仍可在 `tool_usage` 或根因中指出链路未取 KYC，但不触发本封顶。
- 用户只是纯行情、纯事实、客服、图片搜索或资料总结，不属于 05 类个人投资推荐/配置/交易决策支持。
