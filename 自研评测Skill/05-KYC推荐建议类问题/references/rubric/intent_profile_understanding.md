# `intent_profile_understanding` 意图与画像理解

判断模型是否理解用户真正要的推荐或交易决策，并主动获取、识别和使用用户 KYC 信息。

关注点：
- 是否区分推荐股票、推荐 ETF/基金、资产配置、持仓去留、解套、仓位控制等不同任务
- 是否主动读取、调用、检索或引用用户 KYC 数据，而不是只依赖当前问句做通用推荐
- 是否使用画像工具、画像存储、历史 `context`、当前问题自述或其他可见画像来源中的持仓、风险偏好、目标、期限、交易风格
- 是否在“适合我/你觉得我适合什么/结合我的目标风险”场景下形成私人投顾感：明确已知画像、合理推断依据、未知信息和推荐路径
- 当画像缺失时，是否说明缺口并用分层假设或必要追问处理
- 是否避免把“适合我”当成普通榜单、热门标的或通用策略
- 是否避免编造用户画像

常见失败模式：
- 用户问“适合我”，答案完全没有任何画像判断
- 05 类推荐建议问题中，链路没有任何获取或使用 KYC 数据的动作
- 历史 `context` 中已有偏好或持仓，最终答案没有使用
- 可见资料里已有风险偏好或投资记录，最终答案仍声称“你未提供风险偏好/无法判断”
- 把解套、持有、减仓问题误判成一般荐股或资讯总结
- 直接声称用户是稳健/激进/短线风格，但输入没有依据

## 适用性判断

- **始终 relevant**。
