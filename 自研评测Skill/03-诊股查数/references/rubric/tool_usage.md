# `tool_usage` 工具使用合理性

此维度在根因诊断阶段评分，因为需要阅读规划链路。

评分前先阅读 [工具列表](../tool_list/_index.md)。

关注点：
- 结构化行情、财务、分红、资金、股东户数、行业板块数据优先使用 FinQuery。
- 分时或区间成交问题必须使用能支持分钟级/逐笔/分时的工具或明确工具不支持。
- 非公开或结构化库缺失的信息，应补 Search、AccessingFullText、公告、研报、调研纪要等来源。
- 跨市场品种要查询海外价格、国内期货、汇率、单位和合约，不应只套经验值。
- 全市场复杂条件要合理拆分，避免 SQL 条件误解析、工具上限兜底或空结果不复核。
- 对比题应批量取数并进行同口径对齐，而不是逐项零散查询导致口径不一致。

常见失败模式：
- 只用 FinQuery 查不到客户资料后直接放弃，没有搜索或研报补充。
- 主力问题只查资金流，未查龙虎榜。
- 连续 500 根 K 线条件超过工具上限后走兜底，未声明局限也未换策略。
- 工具查询条件把"一个月前上市"解析为刚好等于一个月前那一天。

## 适用性判断

**始终 relevant**，但权重可随任务复杂度调整。
