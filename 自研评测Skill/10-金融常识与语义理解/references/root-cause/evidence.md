# `evidence` — 检索信息

| L2 | 说明 | 典型受影响维度 |
|---|---|---|
| `wrong-entity-evidence` | 检索或引用了相似但错误的公司、基金或产品 | entity_product_boundary |
| `wrong-caliber-evidence` | 指标口径、披露期、价格时点或交易规则证据不对 | metric_caliber_accuracy, timeliness_context |
| `insufficient-definition-evidence` | 缺少定义、公式、市场共识或规则说明 | financial_term_understanding, credibility_expression |
| `stale-evidence` | 用过期数据回答最新/近期/盘中问题 | timeliness_context |
