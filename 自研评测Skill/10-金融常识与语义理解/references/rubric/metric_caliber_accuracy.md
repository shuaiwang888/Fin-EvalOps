# `metric_caliber_accuracy` 指标公式与数据口径

评估对 PE、ROE、主力控盘、ST、披露期、盘中价格等指标口径的处理是否准确。

| 分数 | 标准 |
|---|---|
| 100 | 指标口径完美准确，所有筛选条件、定义和数据来源均可复核 |
| 80 | 指标口径准确，定义清晰，数据筛选合理 |
| 60 | 关键指标口径正确，但个别筛选条件或定义说明不够完整 |
| 40 | 指标口径大致可接受但存在明显缺失或定义不清晰 |
| 20 | 关键指标口径出现实质性错误，严重误导结论 |
| 0 | 指标口径完全错误或使用失真数据不做说明 |

## 常见失败模式

- 指标口径失真：例如 PE 最小直接包含负 PE、主力控盘比例不解释定义
- 使用自定义指标不解释口径和局限
- 指标筛选与投资常识相悖

## 适用性判断

涉及 PE、ROE、主力控盘、ST、披露期、盘中价格等口径时 relevant。
