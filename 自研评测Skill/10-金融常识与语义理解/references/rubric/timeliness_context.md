# `timeliness_context` 时效上下文

评估是否正确处理最新、近期、当下、盘中、报告期等时间要求。

| 分数 | 标准 |
|---|---|
| 100 | 时间语境完美匹配，所有数据时点、报告期和最新状态明确标注 |
| 80 | 时效处理准确，数据时点匹配用户需求，仅有极轻微不足 |
| 60 | 时效处理基本正确，但个别数据时点或报告期说明不够精确 |
| 40 | 时间方向大致正确但细节偏差较大，或部分时间要求被忽略 |
| 20 | 关键时间要求遗漏，使用数据与用户时间语境严重不匹配 |
| 0 | 完全忽略时间要求，使用明显过时数据 |

## 常见失败模式

- 对"最新""近期""当下价格""盘中"等时间词使用错误时点
- 忽略报告期披露时间，使用未披露报告期数据

## 适用性判断

涉及最新、近期、当下、盘中、报告期时 relevant；其他题目 supplementary。
