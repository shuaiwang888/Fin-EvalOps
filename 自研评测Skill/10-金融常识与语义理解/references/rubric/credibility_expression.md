# `credibility_expression` 可信解释与表达

评估答案是否结构清楚、解释到位、避免空泛模板化。

| 分数 | 标准 |
|---|---|
| 100 | 表达完美，先结论后依据，关键信息突出，无模板化套话 |
| 80 | 结构清晰，解释到位，措辞审慎，仅有轻微冗余 |
| 60 | 可读但重点不够突出，部分解释可进一步精确 |
| 40 | 有基本结构但解释不足或套用固定模板 |
| 20 | 表达混乱，空泛模板化，用户难以判断答案立场 |
| 0 | 输出完全无法阅读或严重不符合问答场景 |

## 常见失败模式

- 数据表只能支撑答案，不能代替概念解释和语义判断
- 答案泛泛而谈，缺少与金融语义场景绑定的解释

## 适用性判断

始终 supplementary。若用户要求解释或定义则 relevant。表达质量始终有参考价值。
