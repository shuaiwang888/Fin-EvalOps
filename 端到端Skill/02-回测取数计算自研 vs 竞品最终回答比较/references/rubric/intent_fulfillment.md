# `intent_fulfillment` 意图满足度（权重 13）

判断答案是否真正完成了用户的取数计算任务。

关注点：
- 直接回应了用户的计算需求：是否计算了所要求的涨跌幅、概率、盈亏金额、毛利率等
- 正确处理了隐含意图：用户要求"列出变化超过5个百分点的指标"时，是否完整覆盖所有超标指标
- 没有退化为单纯的数据罗列而跳过计算步骤

常见失败模式：
- 回答了"有哪些相关数据"，但未完成用户要求的计算（如只列数据不算概率）
- 遗漏用户的子任务（如只提取了营收和成本，漏掉了费用指标或对比环节）
- 将用户的计算问题误解为其他类型（如将概率计算理解为排序，将回测理解为选股）

## 适用性判断

- **始终 relevant**。所有题目均考察用户的取数计算需求是否被满足。
