# `data_retrieval_accuracy` 取数准确性（权重 23）

判断答案中引用的数据值是否正确、覆盖是否完整。

关注点：
- 数据值准确性：提取的价格、财务指标、事件日期等是否与实际一致
- 数据覆盖完整性：是否找到了所有符合条件的标的/事件/时间段，样本量是否充足
- 数据深度：长期历史统计是否覆盖了足够的时间范围，而非仅取最近少量数据

常见失败模式：
- 取错基础数据字段（如2024年营业成本取错），导致所有后续衍生计算全部错误（级联错误中基础数据取错归本维度；计算公式/方法错误归 `calculation_accuracy`）
- 统计样本量严重不足（如"上市以来涨停"仅找到最近一年4个事件，而非完整历史）
- 数据覆盖不全（如筛"顺"字股仅找到6只而非完整的31+只），导致排名和统计不可靠
- 行业统计结果颠倒（如有色金属上涨概率最高实为最低），属于数据检索或处理的根本性错误

## 适用性判断

- **始终 relevant**。所有取数计算题目均需考察数据值的正确性和覆盖完整性。
