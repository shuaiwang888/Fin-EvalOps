# `credibility_expression` 可信解释与表达

评估最终回答是否清楚、可信、审慎，是否避免空泛建议和不可验证断言。

| 分数 | 标准 |
|---|---|
| 100 | 表达完美，定义、边界、证据、结论和风险提示均清楚可信 |
| 80 | 结构清晰、措辞审慎，证据和结论匹配良好 |
| 60 | 表达基本清楚可信，但部分断言缺少支撑或结论不够突出 |
| 40 | 有部分可信内容，但结构、证据或语气存在明显问题 |
| 20 | 表达空泛混乱，大量主观断言或模板化建议 |
| 0 | 表达完全不可信，包含严重误导、编造或无法阅读 |

## 常见失败模式

- 数据表只能支撑答案，不能代替概念解释和语义判断
- 答案泛泛而谈，缺少与金融语义场景绑定的解释
- 定义、边界和结论不清，只输出空泛风险提示或模板建议

## 适用性判断

**始终 supplementary**；用户要求解释、定义、区别、操作建议时可提高为 relevant。
