# `financial_term_understanding` 金融术语/规则理解

评估最终回答是否准确解释金融术语、交易规则、市场黑话和财务概念。

| 分数 | 标准 |
|---|---|
| 100 | 概念、规则、例外和市场语义解释完美，专业且可验证 |
| 80 | 术语、规则和市场语境解释准确，常见误区处理较好 |
| 60 | 术语和规则解释基本正确，但边界、例外或适用条件不够清楚 |
| 40 | 理解了部分术语，但关键规则、常见误区或场景含义存在明显问题 |
| 20 | 只做泛泛科普，术语含义、规则或市场语境严重缺失 |
| 0 | 核心金融概念或交易规则完全错误 |

## 常见失败模式

- 规则硬错：例如集合竞价 9:20 当成已成交量、最新季度 ROE 使用未披露报告期
- 对 PE、ROE、ST、集合竞价等基础规则，硬性错误应重扣
- 术语解释停留在泛泛科普，缺少边界、例外和适用条件

## 适用性判断

**relevant**：涉及金融术语、交易规则、市场黑话、财务概念。**supplementary**：只需少量基础常识解释。
