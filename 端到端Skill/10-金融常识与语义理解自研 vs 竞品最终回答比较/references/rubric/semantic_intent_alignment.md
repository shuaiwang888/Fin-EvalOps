# `semantic_intent_alignment` 语义意图匹配

评估最终回答是否读懂用户真实对象、真实任务、错别字、黑话和隐含语义。

| 分数 | 标准 |
|---|---|
| 100 | 完美理解所有显性和隐性语义，能正确纠偏并处理不确定性 |
| 80 | 准确理解真实意图、对象和关键约束，仅有轻微可改进处 |
| 60 | 基本理解用户意图，但个别语义约束或对象范围不够精准 |
| 40 | 部分理解意图，但错别字、黑话、隐含对象或任务边界有明显偏差 |
| 20 | 只抓住表层关键词，遗漏用户核心对象或真实任务 |
| 0 | 完全未识别用户真实意图，答案与问题无关或直接跑偏 |

## 常见失败模式

- 把用户真实对象理解错：例如黄金实物问成 ETF、豪威集团答成豪能股份
- 概念只会查数，不会解释：例如问微盘股定义却给流通市值数据
- 新题材或黑话误判：例如 Token 只按区块链理解，老登股只按上市年限理解
- 面对错别字、俚语和新题材时，未能合理纠偏并说明不确定性

## 适用性判断

**始终 relevant**。判断是否读懂用户真实对象、真实任务、错别字、黑话和隐含语义。
