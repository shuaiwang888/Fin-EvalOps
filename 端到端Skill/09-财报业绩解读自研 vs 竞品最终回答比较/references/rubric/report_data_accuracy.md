# `report_data_accuracy` 财报数据与口径准确性

判断最终回答中的财务数据、报告期、口径和计算是否准确。

关注点：
- 报告期、同比/环比、累计/单季、调整前/调整后、归母/扣非、经营/投资现金流口径正确
- 金额、比例、百分点、股利、分红总额、估值倍数、收入占比等关键数字准确
- 能把差额、占比、敏感度、三项加总等计算闭合
- 明确数据来源和口径，不混用不同报告或不同会计处理后的数字

常见失败模式：
- 把三季报累计营收和年报重述口径混淆
- 只给结论不列核心数字锚点，导致用户无法复核
- 计算差额、同比、占比或估值时使用错误分母
- 引用无法核验或明显幻觉的数据

## 适用性判断

- **relevant**: 问题涉及具体财务指标、报告期、同比环比、分红、估值、股价、会计口径或量化影响
- **supplementary**: 问题主要是定性财报讨论，但仍需基本数据不出错
