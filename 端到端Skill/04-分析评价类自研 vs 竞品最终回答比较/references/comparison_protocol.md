# Result-only 比较协议层

本文件只定义自研 vs 竞品最终回答的 pairwise 比较规则；绝对评分标准由本 skill 的 rubric 体系定义。

## 比较顺序

1. 确认同题：`case_id` 配对到同一问题，问题文本语义一致。
2. 根据用户问题建立双方共享的维度适用性和动态权重。
3. 对自研最终回答与竞品最终回答分别做绝对评分。
4. 逐维比较双方谁更好、差异体现在最终回答哪里。
5. 总结自研最终回答的优点和缺点。
6. 总结竞品最终回答中真正值得学习的优点。
7. 输出双方共同失败点。
8. 给出最终 `verdict`。

## 先绝对、后相对

- 不得因为竞品更差，就把自研的绝对短板写成优势。
- 不得因为自研更差，就忽略竞品也没有达到专家标准。
- 若双方都未通过 hard checks，先写 `shared_failures`，再写相对优劣。
- 若双方都合格，再比较谁更懂场景、证据更关键、时效更准确、投资逻辑更深、方法更匹配、量化更充分、动作更可执行、个人化和情绪处境处理更稳。
- 绝对评分只看单边最终回答，相对比较只看双方最终回答的文本差异。

## 输出对象判定规则

### `self_strengths`

仅收录真正成立的自研优势：
- 自研最终回答相对竞品更强；
- 自研最终回答本身达到该维度基本标准；
- 有自研最终回答位置证据。

常见来源：
- 更准确识别用户真实投资场景和决策问题；
- 更能抓住最新催化、关键证据、专业资料或核心变量；
- 更清楚区分短线交易、题材博弈、价值投资、基金配置、宏观资产和个人化建议；
- 更深入地解释因果链、投资主线、空间、持续性和风险；
- 更有同类/指数/历史分位/估值/回撤/风险收益等量化比较；
- 更明确给出仓位、买卖条件、观察指标、止盈止损或切换条件；
- 更好处理用户在问题中明示的风险目标、资金规模、持仓成本、期限、亏损或焦虑处境；
- 表达更审慎、结构更清楚，不用模板化长篇掩盖低密度。

### `self_weaknesses`

收录自研相对竞品或相对专家标准的真实不足：
- 将投资分析问题误当成事实问答或模板资讯；
- 使用过时消息、浅层证据或无关证据支撑当前结论；
- 核心投资逻辑缺失，只有指标罗列或新闻拼接；
- 方法错位，例如长线问题只看短线技术，题材票只看财务，基金诊断不做同类比较；
- 缺少量化比较、历史位置、同类替代或风险收益指标；
- 给不出可执行动作、触发条件、仓位和风险边界；
- 对“适合我”、持仓成本、亏损、迷茫或急于回本等问题没有做约束；
- 语气过度确定或给出不适当的高风险行动建议。

### `competitor_strengths`

只写竞品最终回答中值得学习的地方：
- 更直接识别用户真实投资决策；
- 证据更关键、更专业、更及时；
- 投资逻辑更成链条，能解释为什么、持续多久、还有多少空间；
- 方法更符合标的属性和投资周期；
- 对比和量化更充分；
- 动作建议更清晰，风险边界更实用；
- 个人化约束或情绪场景处理更稳；
- 表达更可信、更审慎、更少模板化。

不得把篇幅更长、措辞更顺、模型名气或任何不可从最终回答文本验证的因素写成竞品优点。

### `shared_failures`

双方都没达到专家标准时必须填写。典型情况：
- 都没有回答用户真正的买卖/持有/切换/配置决策；
- 都用长期背景或旧消息替代当前催化；
- 都只堆数据、新闻或指标，没有投资逻辑和因果链；
- 都缺少必要的同类比较、量化、历史位置或风险收益分析；
- 都没有给出可执行动作和风险边界；
- 都忽略用户问题里明示的画像、持仓、亏损、期限或情绪处境；
- 都输出过度确定、不可验证或不适合用户场景的行动建议。

## 逐维比较

每个活跃维度都要回答三件事：
1. 谁更强 / 是否打平；
2. 差异体现在最终回答的什么地方；
3. 哪些最终回答证据支撑这个判断。

推荐优先级：
- `intent_scenario_recognition`：先看谁真正识别了投资场景和决策需求；
- `evidence_source_quality`：看谁的证据来源更关键、更专业、更贴近问题；
- `recency_time_boundary`：看谁的最新信息和时间窗口更可靠；
- `investment_logic_depth`：看谁能从事实进入投资逻辑和因果链；
- `method_fit`：看谁的方法更符合标的、资产、周期和用户任务；
- `comparison_quantification`：看谁的量化、对比、排序和历史位置更充分；
- `actionability_risk`：看谁的动作、条件、仓位和风险边界更可执行；
- `user_profile_suitability`：看谁更好处理问题中明示的个人化约束；
- `scenario_emotion_recognition`：看谁更好识别亏损、套牢、迷茫等处境并降低错误决策风险；
- `composition_credibility`：看谁表达更可信、更审慎，但不得压过正确性和投资逻辑。

## 结论语义

- `absolute_summary`：先说双方按专家标准各自好不好。
- `relative_summary`：再说双方谁相对更好。
- `verdict=self_better`：自研相对更好。
- `verdict=competitor_better`：竞品相对更好。
- `verdict=tie`：双方接近，差异不足以形成明确胜负（加权总分差 < 8）。
- verdict 只有以上三个值。双方都不达标时用 `absolute_quality_flag=both_poor` 表达，不影响 verdict 的相对判断。
