# 质量标签：`missing_user_profile_fit`


当用户明确要求个人化推荐或结合自身情况决策，但最终回答没有体现用户问题中明示的画像、资金、目标、期限、持仓、成本或风险约束，导致回答按通用分析或通用推荐处理时触发。

触发条件：
- 用户问“适合我买什么”“结合我的目标风险推荐”“我有 20 万怎么投”“我现在该割肉还是加仓”等。
- 答案没有使用用户问题中明示的风险偏好、投资期限、资金目标、持仓、成本、交易风格或当前自述。
- 问题中没有足够画像信息时，最终答案也没有说明依据不足。
- 直接输出热门标的、通用配置、标准投顾模板或泛泛市场观点。

不触发条件：
- 最终答案已经使用用户问题中明示的画像，并且推荐结论能看出受画像约束。
- 画像信息不足时，答案明确说明依据不足，并给出分层假设、低风险边界或必要追问。
- 用户只是普通市场分析、行情归因或事实查询，不要求个人化适配。
