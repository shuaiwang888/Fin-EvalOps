# `logic_closure` 逻辑闭环（权重 15）

判断答案是否完成了投资逻辑的闭环。

关注点：
- 事件 → 传导路径 → 业务或情绪影响 → 股票含义
- 个股层面的理由论证，而非仅停留在行业层面的评论
- 主题/产业链题要闭环到：题材逻辑 → 关键环节 → 公司主营/订单/产能/客户/财务 → 为什么更值得排前
- 映射题要闭环到：海外标杆逻辑 → 国内可比维度 → 差异与限制 → A 股候选公司
- 数据要服务论点：涨幅、成交、财务、产能、市占率、订单、价格变化、股价表现等指标必须解释其如何支撑结论
- 图表和计算要服务用户决策：优先用市占率、营收占比、产能排名、产量排名、业务占比、估值/营收比等直观指标；不要用难解释的主题数量散点图替代结论
- 对"可能爆发"类题，需要闭环到事件持续性、资金是否正在加速、后续催化、风险和止损/观察条件

常见失败模式：
- 事件与股票之间的因果链断裂
- 开头分析强，但收尾时个股层面的论证弱或缺失
- 只有宏观/行业分析，最后股票理由粗糙、模糊、没有量化证据
- 只解释走势强势或资金流，未解释市场为什么给这个事件或主题定价
- 同一回答内部数据源、异动逻辑、推荐个股逻辑互相打架，用户无法形成信任
- 图表漂亮但指标无解释力，用户仍不知道该买谁、为什么强、强在哪里

## 适用性判断

- **始终 relevant**。所有题目均考察逻辑完整性。
- 无论是事件→传导→股票的因果链，还是条件→筛选→结果的逻辑链，答案都需要完整的逻辑闭环。

## 与相邻维度的边界

- `event_abstraction` 侧重"是否识别了正确的驱动因素"，本维度侧重"驱动因素到个股结论的推理链是否完整闭合"。驱动因素提取正确但传导断裂，扣本维度。
- `industry_mapping` 侧重"事件到产业链的映射是否准确"，本维度侧重"整个推理链（含数据论据）是否自洽闭合"。映射准确但数据未服务论点、因果链断裂，扣本维度。
