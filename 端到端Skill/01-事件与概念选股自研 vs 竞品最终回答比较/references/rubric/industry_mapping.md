# `industry_mapping` 产业链映射（权重 10）

判断答案是否将事件映射到了受益链条。

关注点：
- 事件 → 行业 → 细分领域 → 受益环 → 上市公司的映射
- 区分核心受益、次级受益和弱关联标的
- 区分上游/中游/下游、主营/副业、直接供货/间接供货、品牌厂/代工厂、核心产品/边缘材料
- 对产能、订单、市占率、客户认证、成本、现金流、技术壁垒、国产化率等产业证据给出清晰口径
- 对海外公司或行业标杆映射，拆解业务模式、收入来源、产业位置和壁垒，避免简单标签相似
- 对商品/原材料/主营产品题，产量、产能、资源禀赋、业务占比、成本优势通常比当日涨跌幅更重要
- 对概念交集题，必须判断"双业务深度覆盖"或"核心业务重合"，不能只说同时属于两个主题
- 对产业链上游设备材料题，需说明代表公司的原因、产能/出货/客户验证/认证进度/技术壁垒和国产替代空间

常见失败模式：
- 只有主题名称，没有链条映射
- 混合列表中包含了下游或低相关性公司但没有区分
- 把"上游材料"理解成狭义单一材料，或把用户要求的细分环节扩散成泛产业链
- 将弱关联、概念蹭边、互动易模糊表述与核心主营标的一视同仁
- 将代工厂误判为品牌厂对标，或将业务模式完全不同的公司硬凑为海外巨头映射
- 只用所属概念、涨跌幅或市值证明相关性，没有业务深度、产能或产品证据

## 适用性判断

- **relevant**: 题目需要产业链分析、受益链条映射、上下游关系梳理、主营产品核验、产能份额比较、客户供货确认、概念交集深度核验或海外映射
- **supplementary**: 题目涉及行业板块但核心诉求是条件筛选
- **not_applicable**: 纯数据查询（如涨幅排名、均线筛选）无产业链映射需求
