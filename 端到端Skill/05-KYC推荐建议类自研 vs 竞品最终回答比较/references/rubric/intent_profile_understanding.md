# `intent_profile_understanding` 意图与画像理解

判断最终回答是否理解用户真正要的推荐或交易决策，并处理用户问题中明示的个人化约束或画像不足。

关注点：
- 是否区分推荐股票、推荐 ETF/基金、资产配置、持仓去留、解套、仓位控制等不同任务。
- 是否使用用户问题中明示的持仓、风险偏好、目标、期限、资金规模、交易风格、成本或亏损状态。
- 是否在“适合我/你觉得我适合什么/结合我的目标风险”场景下形成私人投顾感：明确已知信息、未知信息、审慎假设和推荐路径。
- 当画像信息不足时，是否说明缺口并用分层假设或必要追问处理。
- 是否避免把“适合我”当成普通榜单、热门标的或通用策略。
- 是否避免编造用户画像。

常见失败模式：
- 用户问“适合我”，答案完全没有任何画像判断或画像不足说明。
- 用户问题已经给出风险偏好、资金目标、期限、持仓或亏损状态，最终回答没有使用。
- 把解套、持有、减仓问题误判成一般荐股或资讯总结。
- 直接声称用户是稳健、激进、短线或长期风格，但用户问题没有依据。
- 只列热门产品或标的，没有说明为什么适合这个用户。

## 适用性判断

- **始终 relevant**。
