# `risk_boundary_control` 风险控制与边界

判断最终回答是否在推荐中保持适当性、风险揭示和不确定性表达。

关注点：
- 是否提示主要风险：逻辑证伪、估值过高、业绩不及预期、政策变化、流动性、波动、消息退潮。
- 是否给出止损、止盈、仓位上限、回撤容忍、观察条件。
- 是否避免确定性收益、确定性底部、必涨、稳赚等表达。
- 高风险、短线、主题、单一行业推荐是否有更严格的仓位和适用人群边界。
- 对亏损或套牢用户是否先控制风险，再讨论补仓或反弹。
- 对迷茫、连续亏损或急于回本用户，是否先建议暂停追热点、降低仓位/频率、复盘交易纪律，而不是继续刺激短线。

常见失败模式：
- 推荐具体标的但没有任何风险和仓位边界。
- 对底部时间、未来收益、短期反弹给过度确定判断。
- 用户已深套却鼓励加仓，没有证伪条件和风险承受说明。
- 把风险提示写成模板免责声明，和具体建议无关。
- 对普通用户默认推荐窄主题 ETF、单一行业或短线股票，却没有说明集中暴露和波动风险。

## 边界说明

- 与 `decision_actionability` 的边界：本维度关注“推荐是否有风险边界和止损条件”，`decision_actionability` 关注“是否给出可执行的买卖和仓位建议”。
- 与 `scenario_emotion_recognition` 的边界：本维度关注“是否给出风险控制措施”，`scenario_emotion_recognition` 关注“是否识别用户情绪和处境”。

## 适用性判断

- **始终 relevant**。
