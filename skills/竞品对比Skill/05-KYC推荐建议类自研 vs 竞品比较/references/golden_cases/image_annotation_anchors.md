# 图片人工批注锚点

本文件沉淀 `04_KYC Recommendation Suggestions.docx` 截图中的红绿批注和模型回答对照。它补充 `_index.md` 的 13 个正文案例，重点约束“看起来有推荐，但没有像私人投顾一样理解用户、稳定取舍和给出可执行动作”的失败模式。

## 使用规则

- 评分时先用 `_index.md` 匹配正文案例；若题目涉及“适合我”、ETF/基金推荐、亏损迷茫、持仓去留、宏观配置、多资产/多行业取舍、仓位控制或具体标的推荐，继续使用本文件 hard checks。
- 截图批注优先校验最终答案是否真正解决用户的投资决策，而不是校验回答是否写得长、数据多、表格多或免责声明完整。
- 触发本文件任一失败模式时，优先映射到 `intent_profile_understanding`、`suitability_personalization`、`decision_actionability`、`risk_boundary_control`、`evidence_integration`、`composition_credibility`、`tool_usage`；ETF/基金产品池或多次推荐不稳定时可启用 `product_universe_fit`、`recommendation_stability`。

## 通用人工批注规则

### 1. “适合我”必须像私人投顾，不是普通榜单

hard checks:
- 用户问“适合我”“结合我的目标风险”“你觉得我适合什么”时，模型应主动读取或利用可见 KYC、历史提问和投资记录，至少识别风险偏好、期限、资金规模、持仓/成本、交易经验、偏好行业或亏损状态。
- 若系统中已有画像或历史信息，最终答案还说“你未提供风险偏好/无法判断”，属于画像使用失败；即使答案后面给了标的，也要扣 `intent_profile_understanding`、`suitability_personalization` 和 `tool_usage`。
- 高质量答案可以基于历史提问风格做审慎推断，但必须标注依据和不确定性，例如“从你的提问看更像偏研究驱动/能跟踪验证/允许中期持有”，不能无依据编造稳健型、激进型、短线型。
- “私人投顾感”不是多说安抚话，而是让推荐路径受用户画像约束：你为什么适合这种资产、为什么不适合那种资产、当前缺哪些信息会改变建议。

### 2. ETF/基金推荐先看配置角色和产品池适配

hard checks:
- 普通“推荐两只适合我的 ETF/基金”不应默认给医疗、5G 等窄行业高波动主题。除非用户画像或市场约束支持主题暴露，否则应优先考虑宽基核心仓、红利/低波防守、债券/货币/黄金等组合角色。
- 高质量 ETF 推荐应说明两只产品的互补关系，例如“核心底仓 + 成长卫星”“宽基压舱石 + 防守增强”，并给出规模、流动性、费率、波动/回撤、跟踪指数、持有期限和配置比例。
- 只说“近一年收益高、回撤低、行业分散”但没有说明为什么适合该用户、产品在组合里的角色和买入节奏，不能给高分。
- 推荐同类问题多次输出不同产品时，必须解释变化原因：市场环境变化、用户画像变化、约束变化或产品数据变化。无解释的不稳定推荐应扣 `recommendation_stability`。

### 3. 用户明确要“买哪些股票”时，不能只给框架

hard checks:
- 用户要求“应该买哪些股票/推荐股票/短线可参与哪些标的”时，答案应在风险边界内给出具体候选、角色、优先级、仓位上限、买入/持有/卖出规则；只给“你再告诉我两个信息我就能给清单”不够。
- 可以先做风险评估和组合框架，但如果已有足够条件，应给可参考标的或至少给可执行筛选清单和当前更值得盯的方向。
- 标的越具体，风险控制越要具体：单票上限、行业集中上限、止损/止盈、证伪条件、观察信号、复盘周期。
- 直接列一堆代表性股票但不说明为什么适合用户、怎么分仓、什么情况下退出，也不能给高分。

### 4. 宏观/市场环境题要先定环境，再映射仓位

hard checks:
- 用户问“当前宏观环境怎么投资”“弱复苏低通胀利率下行怎么配”时，答案应先定义环境变量，再映射到资产/行业/仓位/期限，而不是直接套标准资产配置表。
- 需要解释“为什么现在这样配”：政策、利率、通胀、盈利、估值、流动性、风险偏好与市场阶段如何影响权益、固收、商品、现金和行业方向。
- 计算过程、图表和历史回测应服务结论。若计算细节冗长、关键结论被淹没，扣 `composition_credibility`；若关键数据缺失，扣 `evidence_integration`。
- 对新手或普通用户，宏观配置建议应给可执行产品形态和节奏，避免只给抽象板块或过多专业术语。

### 5. 持仓去留必须给条件化动作

hard checks:
- 浮盈、浮亏、快腰斩、是否继续持有、割肉还是加仓类问题，应给出持有/减仓/卖出/等待/补仓的条件化方案，不能只分析行业或基本面。
- 高质量答案会把行情证据转成动作：均线、RSI、成交量、主力资金、融资余额、估值、基本面催化、行业景气等必须对应到止损、止盈、回补、加仓或观察条件。
- 浮盈场景不能只喊继续看好，应保护利润，例如先落袋一部分、剩余仓位设止损/止盈线、反弹确认再处理。
- 深套场景不能急着抄底或鼓励加仓，应先区分政策底、市场底、基本面底，说明个股风险、补仓条件和“不能加”的情形。

### 6. 多资产/多行业比较要给取舍，不是并列说明

hard checks:
- “黄金还是原油”“银行/家电/白酒/创新药选两个”“资源/机械/建材/券商/银行谁优先”必须给排序、配置比例或适配场景，不能只列各自优缺点。
- 高质量答案应使用用户要求的比较维度：收益、波动、回撤、估值分位、盈利确定性、历史类似阶段、启动顺序、弹性、持续性、资金面。
- 若用户要求历史阶段、估值分位、盈利确定性而答案没有给关键数据或数据不可核验，即使思路高级，也应触发 `missing_required_evidence` 或显著扣分。
- 对“稳健配置 vs 进攻博弈”要明确：稳健用户配什么、进取用户配什么、各自仓位和止损边界。

### 7. 亏损迷茫先修决策系统，不要继续刺激短线

hard checks:
- “很迷茫，不知道买什么，感觉买什么都是亏”首先是持续亏损后的无力感、信心受挫和决策失灵，不是普通选股需求。
- 高质量答案应先降风险、降频交易、复盘亏损来源、控制仓位、建立买入/卖出纪律，再讨论少量核心资产或 ETF；不宜直接给短线、抓反弹、热门板块或个股筛选。
- 应明确“你现在缺的不是一只股票，而是一套不被情绪打崩的投资方法”，并把方法落到分批、仓位、止损、观察清单。
- 若答案把该场景当成普通短线荐股，即使给了大量市场分析，也应触发 `misread_emotional_loss_context`。

### 8. 盘面分歧和短线参与要联动当前状态

hard checks:
- 用户提到“短期反弹后分歧阶段”“震荡上行主线”“短线参与哪些标的”时，答案应先定义盘面状态，如上涨/下跌家数、涨跌停、量能、资金流、主线延续性，再推导仓位。
- 高质量答案会把主线拆成核心仓和卫星仓，说明哪些方向低吸、哪些方向只做事件博弈、哪些信号出现应降仓。
- 常规模板化仓位比例、板块清单和个股名单，如果没有与当前盘面分歧状态联动，应扣 `decision_actionability` 和 `evidence_integration`。

## 扣分速查

- **不懂我**：有“适合我”诉求，但没有读取、引用或审慎推断用户画像。
- **假懂我**：无依据编造风险等级、资金规模、期限或风格。
- **只像产品推荐榜**：ETF/基金只按收益、回撤、热门主题推荐，没有配置角色和用户适配。
- **只给框架不交付**：用户要买哪些股票，答案不给候选、仓位、触发条件或退出规则。
- **只给报告不决策**：行业/宏观分析很全，但没有回答买什么、卖什么、配多少、什么时候动。
- **只刺激交易**：亏损、迷茫、深套场景继续推荐短线、抓反弹、追热点。
- **只会每次换答案**：同类 KYC 推荐反复变化，没有市场、画像或约束变化解释。
- **只讲确定性**：对底部时间、反弹空间、收益目标、加仓机会过度确定，没有证伪条件。
