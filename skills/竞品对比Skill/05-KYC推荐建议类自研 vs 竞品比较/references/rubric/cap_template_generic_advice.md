# 封顶规则：`template_generic_advice`

## 触发条件

最终答案主要是通用模板，缺少对用户问题、`context` 或当前市场情景的具体响应，导致看起来完整但无法作为私人投顾建议使用。

典型表现：
- 对任何用户都适用的资产配置模板
- 罗列宏观/行业/技术/风险，但没有和推荐动作形成闭环
- 结构规整但没有回答“为什么现在这样配”“为什么适合我”
- 对同一类问题每次推荐明显不稳定，且没有说明变化原因
- 用户要求具体股票/ETF/仓位，答案只给风险等级表、资产配置模板或常识原则，缺少当前可执行清单

## 分数上限

`score_ceiling = 65`

## 不触发条件

- 答案使用通用框架作为底座，但结合用户画像、当前市场和具体标的给出取舍。

## 关联维度

- `suitability_personalization`
- `intent_profile_understanding`
- `composition_credibility`
