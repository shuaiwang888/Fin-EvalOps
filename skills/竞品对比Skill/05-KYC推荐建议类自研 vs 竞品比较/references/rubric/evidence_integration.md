# `evidence_integration` 多维证据整合

判断模型是否用足够、匹配且可核验的证据支撑推荐建议。

关注点：
- 是否根据题目需要整合宏观、政策、行业、估值、盈利、技术、资金、情绪、历史阶段等信息
- 多资产、多行业或多基金比较时，是否有横向比较和取舍依据
- 用户要求历史类似阶段、估值分位、盈利确定性、收益波动等数据时，是否给出关键数据
- 是否把证据转化为推荐逻辑，而不是数据堆砌
- 是否避免用旧信息、浅层资讯或无关指标支撑当前建议
- 宏观配置题是否先定义环境变量，再把政策、利率、通胀、盈利、估值、流动性和风险偏好映射到仓位与资产选择
- 持仓去留题是否把均线、RSI、资金、融资、估值、基本面催化等证据转成持有/减仓/止损/加仓条件

常见失败模式：
- 思路看起来高级，但关键数据没有给出来
- 只有宏观口号或行业概念，没有估值、盈利、价格、资金或历史验证
- 技术分析权重过高，脱离用户期限和产品属性
- 引用工具结果但没有解释它如何支持推荐
- 图表或计算很多，但用户仍看不出为什么要这样配、买谁、卖谁或等什么信号

## 适用性判断

- **relevant**：需要市场、宏观、行业、估值、技术、资金、历史阶段证据。
- **supplementary**：纯原则性建议或用户主要要求风险框架。
- **not_applicable**：仅要求询问用户画像或说明信息不足。
