# L1: `tool`

用于归因工具选择、输入、输出读取或编排问题。

常见 L2：
- `wrong-tool-choice`：结构化数据、新闻、公告、回测或深度网页阅读使用了不合适工具。
- `poor-tool-input-window`：工具输入缺少关键时间窗口、标的、行业或比较对象。
- `missing-tool-for-required-data`：需要关键数据但没有调用对应工具。
- `tool-output-unused`：工具结果没有进入最终答案。

证据要求：
- 引用 `chain.tools[M]` 的工具名、输入或输出摘要。
- 说明工具问题如何影响具体评分维度。
