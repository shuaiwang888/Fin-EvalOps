# `data_logic_rigor` 数据与逻辑严谨性

判断数据口径、计算方法、案例真实性和推演逻辑是否可靠。

关注点：
- 回撤、涨跌幅、收益率、库存、产能、利润贡献、估值、合约盈亏等计算口径是否正确
- 时间窗口是否严格匹配用户要求
- 案例、先例、榜单、龙虎榜、涨停板、资金流等是否可信可核验
- 横向比较是否使用同一口径，避免把需求量、价值量、利润弹性混为一谈
- 推演是否自洽，是否避免无依据的概率和点位判断

常见失败模式：
- 最大回撤口径错误，例如用月初到月末收盘替代月内最高到最低
- 案例失实或数据无依据
- 表格中的涨跌幅、资金净流入、板块强度错漏
- 声称“利润贡献/估值合理”但没有量化口径
- 具体价位和收益测算像直接报区间，论证基础不足
- 用公司整体营收、利润或估值替代某条产业链/新业务的利润贡献，却不说明口径限制
- 混用需求量、价值量、利润弹性、价格弹性，导致“最受益”结论不可比
- 正套/反套、近远月价差、盈亏方向和公式不一致

## 适用性判断

- **relevant**：涉及计算、回撤、估值、利润、案例、榜单、量化对比、时间窗口。
- **supplementary**：纯框架型问题。
- **not_applicable**：没有数据或事实严谨性要求的开放讨论。
