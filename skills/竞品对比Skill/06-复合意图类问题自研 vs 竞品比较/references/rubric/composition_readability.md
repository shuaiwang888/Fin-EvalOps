# `composition_readability` 结构与可读性

判断答案是否在复杂问题中保持清晰结构、可读性和结论聚焦。

关注点：
- 是否先给总判断，再按子任务展开
- 是否用表格、分段或列表降低复杂度
- 是否避免表格过杂、结论不凝练、重点发散
- 是否把多层问题组织成用户可追踪的主线
- 是否避免报告感很强但核心决策难以提取

常见失败模式：
- 内容像摘要或提纲，展开不足
- 表格很多但主结论不清
- 结构规整但像模板，缺少针对原题的组织
- 关键信息埋在长段落中
- 表格列很多但口径、单位、时间窗口或比较对象不一致，导致用户无法直接使用
- 可视化或表格形式不匹配，例如长时间序列硬塞成密集表格，反而遮蔽现金流、利润、研发费用等关键趋势
- 先写大段背景，最后才轻描淡写回答合约、价位、调仓、先例等用户真正要的结论

## 适用性判断

- **始终 supplementary**。
