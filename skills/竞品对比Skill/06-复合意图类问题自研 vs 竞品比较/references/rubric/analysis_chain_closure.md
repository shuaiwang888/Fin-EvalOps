# `analysis_chain_closure` 分析链路闭环

判断答案是否形成“事实—影响—传导—策略”的闭环，而不是停留在资料罗列或观点跳跃。

关注点：
- 是否先明确事实和数据，再解释影响，再归纳传导路径，最后给策略或结论
- 地缘、政策、产业事件是否有可复用的风险传导路径
- 行业或公司调研是否从竞争格局、技术路线、市场份额映射到投资线索
- 交易问题是否从前提、结构、价位、盈亏测算推到执行建议
- 是否避免只有结论没有中间机制，或只有机制没有用户能用的结论

常见失败模式：
- 数据或资讯很多，但没有传导链
- 结论偏泛，缺少标的、环节、利润或策略落点
- 横向比较不足，导致无法判断谁更优
- 情景推演只有宏观叙述，缺少触发标准和概率依据

## 适用性判断

- **始终 relevant**。
