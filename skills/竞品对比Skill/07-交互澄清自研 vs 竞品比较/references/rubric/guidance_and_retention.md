# 后续引导闭环

评估答案是否让交互澄清形成下一步闭环。该维度关注 doc 中指出的"问完即走、无法形成持续价值"问题，但不能用泛泛留存话术替代必要澄清和规则纠错。

高分要求：
- 引导与当前咨询直接相关：价格触发、风险提醒、同类标的异动监控、财报/分红日提醒、策略复查。
- 对需要补充信息的问题，追问清楚下一条用户最该回复什么。
- 对用户已得到结论的问题，给出可订阅或可继续跟进的任务型建议。
- 后续动作应服务当前澄清任务，例如补充成本/周期、复查权限、监控除权日、跟踪关键价位，而不是泛泛扩展话题。

低分模式：
- 只有"如果还有问题可以继续问"。
- 明明用户问产业链地位，却只问"要不要核心企业清单"，不主动给关键标的。
- 回答结束后没有提供任何持续观察点。
