# tool_usage

链路是否正确使用工具核验时间、交易日历和数据时点。

## 适用性判断

- 适用：需要外部交易日历、行情、公告、财报、分红、跨市场数据或最新状态的问题。

## 评分锚点

- 100 分：选择合适工具，输入日期/市场/报告期正确，输出日期被正确带入最终答案。
- 80 分：工具选择和主要输入正确，存在次要字段遗漏但不影响结论。
- 60 分：工具方向对，但没有充分核验市场日历或 as-of。
- 40 分：工具调用不足或输入有明显瑕疵，导致答案时间边界含混。
- 20 分：应查却不查，或查错市场/日期/报告期。
- 0 分：工具证据与答案相反，仍输出错误结论；或编造工具不可支持的时间事实。

其他分值按 [raw-score-scale.md](raw-score-scale.md) 在相邻锚点之间保守插值。

## 比较注意

工具数量不等于工具质量。比较时看工具是否核验了本题关键时间前提，并是否改善最终答案。
