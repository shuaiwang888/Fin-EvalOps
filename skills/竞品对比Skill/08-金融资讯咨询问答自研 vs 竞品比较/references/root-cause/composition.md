# L1: composition

系统可能有部分信息或逻辑，但最终答案组织不好。

| L2 | 说明 | 常见受影响维度 |
|---|---|---|
| `data_dump_no_judgment` | 信息很多但没有主线、比较结论或投资判断 | `information_integration`, `core_signal_extraction` |
| `key_signal_not_prominent` | 提到核心因素但淹没在大量次要信息里 | `core_signal_extraction`, `credibility_expression` |
| `unclear_structure` | 结构混乱，用户难以看出时间线、分类或结论 | `information_integration`, `credibility_expression` |
| `source_uncertainty_not_marked` | 传闻、纪要、大V观点没有清楚标注边界 | `credibility_expression`, `fact_evidence_quality` |
| `overlong_or_generic_expression` | 啰嗦、套话、宽泛表达削弱可用性 | `credibility_expression` |
