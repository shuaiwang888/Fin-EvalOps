# nonstandard_source_awareness：非标准资讯意识

评估答案是否意识到市场小段子、调研纪要、金融大V文章、官媒截图等材料在强时效金融问答中的价值与边界。

## 评分锚点

- 0：该用非标准资讯时完全无意识，导致主因缺失。
- 20：泛泛提到传闻/文章，但没有利用其核心信息。
- 40：使用了相关线索，但没有区分传闻、纪要、官媒、公告等来源边界。
- 60：能利用非标准资讯补充解释，但核验和表达边界一般。
- 80：能把非标准资讯作为线索并交叉验证，表达审慎。
- 100：能高效结合小段子/纪要/大V/官媒截图抓重点，并清楚区分事实、传闻和观点。

## 使用原则

- 市场小段子常用于识别热点和盘中异动原因。
- 调研纪要常提供产量、投产、客户、内部进展、业绩拆分等公开资料缺失的信息。
- 金融大V文章常帮助模型抓住市场关注的主因和用户爱看的解释角度。
- 以上来源不能无条件当作事实，必须标明不确定性和验证需求。
