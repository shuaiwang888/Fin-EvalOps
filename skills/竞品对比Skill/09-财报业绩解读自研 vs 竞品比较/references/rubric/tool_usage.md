# `tool_usage` 工具使用合理性

此维度在根因诊断阶段（协议步骤 2）评分，因为需要阅读规划链路。

评分前先阅读 [工具列表](../tool_list/_index.md)。

关注点：
- 结构化财务数据、行情、估值、区间涨跌幅、财务科目用 FinQuery 等金融查询工具
- 公告全文、年报附注、季报说明、会计差错更正公告、分红公告、官网公告、审计意见、业绩说明会应使用 Search/AccessingFullText，并带"公告""年报""一季报""会计差错更正""分红方案"等关键词
- 行业价格、成本机制、市场预期、机构一致预期、存储价格周期、火电电价煤价等外部背景需要 Search/研报/资讯补充
- 复杂问题应交叉验证：财务数据 + 公告原文 + 行业背景 + 行情反应
- 答案在截图中失败的高频原因是只调用金融查询，未规划搜索或全文读取，导致没命中官方披露原文

常见失败模式：
- 用 FinQuery 的结构化字段替代公告全文，错过官方原因
- 搜索词过宽，未包含公司名、报告期、公告类型和关键会计事件
- 全文获取失败后没有换渠道验证
- 对利润差异、现金流差异、估值对比等需要计算的问题未做清晰测算
- 多轮工具调用耗时长但没有增加关键信息

## 适用性判断

- **始终 relevant**。所有财报业绩解读题均需评估工具策略。
