# `composition` — 组织答案

当推理可能存在但答案表达不佳时使用。

| L2 | 说明 | 典型受影响维度 |
|---|---|---|
| `data-dumping` | 冰冷的表格替代投资论点，指标罗列但没有解读 | credibility_expression, intent_fulfillment |
| `vague-subjective-style` | 断言无可验证依据，说一半藏一半，或过度回避核心判断 | credibility_expression |
| `plan-answer-drop` | 链路中有好想法但最终答案丢失，或个股理由未在答案中呈现 | 多维度 |
| `flat-no-hierarchy` | 表格或段落没有梯队、主次、强弱或结论先后，用户无法快速定位核心标的 | ranking_judgment, credibility_expression |
| `over-fragmented-versions` | 给出多个版本、多个分类或碎片化观点，却没有收敛成可执行结论 | intent_fulfillment, credibility_expression |
