# `credibility_expression` 可信度与表达（权重 5）

判断答案是否直接、客观、可验证。

关注点：
- 有支撑的清晰断言
- 直接的措辞，而非模糊的"说一半藏一半"式表达
- 主动标注不完全对标、数据口径不确定、间接供货、业务占比小等限制，且不让限制淹没核心判断
- 表格和文字服务于决策：读者能看出核心票、边缘票、理由和证据强弱
- 关键结论要有可验证依据，避免"市场研究显示""常被提及""有望受益"这类空泛措辞
- 表格字段应让普通用户能读懂：例如"核心产品/产量/产能/市场份额/受益逻辑/风险"优于"主题命中数量/复杂散点坐标"
- 对比类答案要系统化：用多维表格覆盖核心候选，而非只选一个结论后补理由

常见失败模式：
- 主观、模糊或过度戏剧化的语言
- 没有增加证明力的第三方式填充内容
- 为迎合用户强行给出不存在或不可靠的精确对标、供应关系、产能排名或涨幅数据
- 答案分类混乱、版本过多、碎片化，缺乏执行性
- 结构信息扁平，除涨幅和概念标签外没有任何能帮助用户理解题材贴合度的信息

## 适用性判断

- **始终 supplementary**。表达质量在所有题目中均有参考价值，但通常不是核心评判维度。
