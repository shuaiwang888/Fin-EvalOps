# 整体链路比较层

本文件说明如何基于真实数据结构比较两边整体链路，并把链路差异解释回最终答案差异。

## 真实输入形状

### 自研模型常见形状

- `text_answer` 通常有值；
- `chain` 通常有多个 step；
- 每个 step 可能包含：
  - `plan`
  - `tools` list
- 工具调用常分散在多个 `chain[N].tools[M]` 中。

### 竞品模型常见形状

- `text_answer` 可能为空；
- 最终答案常在 `answer` 中；
- `chain` 可能只有一个 step；
- `plan` 可能为空字符串；
- 工具调用仍然存在，通常位于 `chain[0].tools`，其值是 list。

## 字段读取原则

- 最终答案主锚点：
  - 自研优先 `text_answer`；
  - 竞品若 `text_answer` 为空，则使用 `answer`。
- `tool_usage` 是评测维度，不是 JSON 字段。
- 工具调用主路径：`chain[N].tools[M]`。
- 顶层 `tools` 即便存在，也可能为 `null`，不能替代 `chain[*].tools[*]`。
- 当 `plan` 为空时，不要臆造不可见推理；直接基于工具行为、工具输出、数据口径、最终答案做归因。

## 比较什么

整体链路比较不是比较“谁的链路更长”，而是比较谁的链路更能产生高质量答案：

1. **意图和场景识别**
   - 是否判断题目是简单查数、多标的对比、轻量诊断、跨市场比价、全市场筛选还是宏观数据查询；
   - 是否识别隐含金融语义，例如主力、筹码、增长点、止盈位、行业跑赢原因；
   - 是否处理多义词和隐含约束，而不是只按表层关键词取数。

2. **工具选择**
   - 结构化行情、财务、资金、行业、宏观数据是否使用 FinQuery 等合适工具；
   - 历史序列、全市场条件、连续 K 线、跑赢统计是否使用 BackTest 或等价可复现工具；
   - 非公开客户、订单、增长点、研报、调研纪要、公告和新闻是否使用 Search / AccessingFullText 补充；
   - 跨市场商品、期货、汇率和合约问题是否使用能够覆盖对应口径的数据源；
   - 复杂表格、换算、对比或可视化是否合理使用 CodeInterpreter；
   - 是否存在该用工具而未用、工具选错、重复调用、参数错误或工具失败未兜底。

3. **查询设计**
   - 查询参数是否精确覆盖标的/代码、市场、行业、日期、交易日、复权、合约月份、单位、汇率、字段和筛选条件；
   - 是否处理“过去 N 年”“上市以来”“最近一次”“今年分红”“节前 N 个交易日”“一共涨幅”“一个月前上市”等高风险表达；
   - 是否避免用过宽泛或错误类型的数据替代关键证据。

4. **证据覆盖与交叉验证**
   - 是否给出必要的数据明细、年份序列、样本量、字段来源、公式、筛选逻辑和计算过程；
   - 是否在结构化数据、搜索、公告、研报、调研纪要、龙虎榜和资金流之间做必要核验；
   - 是否处理空结果、异常值、工具上限和冲突口径，而不是机械拼接。

5. **证据向答案的转化**
   - 查到的数据是否真正支撑最终判断、差异、原因、风险、观察点或可操作建议；
   - 是否存在“链路里查得不错，答案里却漏写/算错/不可验证”的断层；
   - 是否存在“工具很多，但仍然只输出数据堆砌”的伪复杂。

6. **呈现和可视化**
   - 多年份、多标的、趋势对比或图表场景，是否用表格/图表提升理解；
   - 图表是否有解释，是否转译为关键结论、差异和投资含义；
   - 不能让漂亮图表掩盖核心数据或口径错误。

## 如何解释答案差异

优先写成“链路动作 → 答案结果”的形式：
- 因为自研同时查询资金流和龙虎榜，所以对“主力”语义覆盖比只看单一资金字段更完整；
- 因为竞品补充了公告/调研纪要，最终能把“增长点”写成边际变化，而不是存量业务介绍；
- 因为自研没有校验复权口径和交易日，导致过去 N 年涨跌幅对比不可靠；
- 因为竞品虽然 `plan` 不可见，但其 `chain[0].tools` 覆盖了分红明细、年份序列和来源，因此最终答案更可验证；
- 因为自研图表较多但没有解释差异和投资含义，所以呈现信号不能抵消洞察不足。

## 不应做的事

- 不因为自研 chain step 更多，就自动判断其链路更好；
- 不因为竞品 `plan` 为空，就直接把它判成“无推理”；
- 不把 `tool_usage` 误当成 JSON 字段；
- 不只比较工具数量，而忽略这些工具是否真的改善了数据、口径、诊断框架和可复核性；
- 不用表达流畅或图表漂亮掩盖核心数据、时间口径、分析框架或样本错误；
