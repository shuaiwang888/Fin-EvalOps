# `expression_quality` 表达与展示质量（权重 7）

判断答案的表达是否清晰、专业，数据展示是否直观。

关注点：
- 结构化展示：是否使用表格展示数据、是否有汇总表、计算过程是否分步骤呈现（侧重**呈现可读性**；结果是否可独立验证属于 `result_verifiability`）
- 专业性：使用专业金融术语（如"前复权"、"涨停"、"区间涨跌幅"）且表述准确
- 可读性：数据密集型答案是否有层次感，关键结论是否突出
- 金融产品体验：多标的、多日期、多指标场景是否提供综合汇总表，让资金前后对比、概率样本和筛选结论一眼可读

常见失败模式：
- 缺少汇总表：多标的盈亏计算仅逐个列出，未生成综合对比表
- 数据堆砌无整理：大量原始数据直接输出，无排序、无筛选、无高亮
- 计算过程混乱：公式、代入、结果混杂在正文中，缺乏结构化展示
- 只给口头结论：没有用表格承载关键字段，削弱专家评论强调的对客金融产品体验

## 适用性判断

- **始终 supplementary**。表达质量在所有题目中均有参考价值，但在数据准确性面前优先级较低。
