# tool：工具信源

用于解释工具选择、输入和读取输出的问题。

L2：
- `wrong_tool_selection`：结构化行情条件和非标搜索条件的工具选择颠倒。
- `poor_search_keywording`：直接搜索长原问句，未拆出核心关键词。
- `missing_cross_validation`：合作关系、订单、极端利好、主线题材等非标事实缺少公告/研报/资讯交叉验证。
- `tool_output_misread`：工具已有字段或返回结果被误读、漏读或与最终答案冲突。

证据应优先引用 `chain[N].tools[M]` 和 `chain[N].tools[M].output`。
