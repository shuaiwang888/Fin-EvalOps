# 工具与信源匹配

评估链路中工具选择、关键词聚焦、参数、交叉验证和工具输出读取是否匹配复杂选股任务。

## 六档锚点

- `0`：应使用工具却完全未使用，或工具选择全部错误。
- `20`：关键非标信息、行情数据或计算任务使用了明显错误的工具。
- `40`：工具选择部分合理，但关键词不聚焦、参数错误或缺少必要交叉验证。
- `60`：工具使用基本合理，但存在冗余调用、漏查信源或工具输出读取不充分。
- `80`：结构化取数、搜索、计算和验证工具匹配良好，参数和关键词较准确。
- `100`：工具编排精准高效，结构化与非标证据分工清楚，最小调用完成充分验证。

## 常见扣分点

- 将用户原问句整句丢给 Search，未拆出“英伟达合作”“算力调度”“极端利好事件”等聚焦关键词。
- 将概念、主题、合作关系、订单、公告/研报总结标签完全交给 FinQuery。
- 应使用 FinQuery/BackTest/CodeInterpreter 处理结构化行情、回撤、排序和分时计算却未使用。
- 工具返回为空或错误时不重试、不降级、不解释边界。
