# 工具与信源匹配

复杂选股要把结构化条件、非标产业信息和计算验证拆开处理。

## FinQuery

适合：
- 行情、财务、资金、技术指标、板块、代码前缀、ST/退市/上市时间等结构化条件。
- 输出股票代码、简称、涨跌幅、成交额、换手率、市值、均线、资金净流入等字段。

不适合：
- 合作关系、订单、主线题材、极端利好、核心技术、护城河、与巨头深度合作等非标信息。

## Search

适合：
- 公告、研报、资讯、互动易、合作关系、订单、主线题材、事件催化、极端利好等非标信息。
- 搜索应拆关键词，不能直接把长原问句整体丢入搜索。

## BackTest

适合：
- 历史窗口、涨停后表现、区间收益、回撤、策略条件历史验证。

## CodeInterpreter

适合：
- 工具返回数据后的二次计算、排序、交集、公式验证、时间窗口校验。

## Forecast / AccessingFullText / SearchImage / CustomerServiceFAQ / SaveUserProfile

按需使用。复杂选股一般不应把这些工具作为主工具，除非用户明确需要预测、全文材料、图像信息、客服规则或用户画像保存。

## 常见错误

- 非标搜索条件全部丢给 FinQuery。
- 结构化行情条件全部交给 Search。
- 搜索关键词不聚焦，长问句原样搜索。
- 工具返回空结果后直接结束，不解释边界、不调整分层策略。
