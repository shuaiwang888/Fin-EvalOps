# 专家答案模式

本文件沉淀人工精标截图中的隐性评判标准。评分时用它校准“看起来完整”和“真正有投资价值”的差异。

## 总原则

- 用户问分析评价，大多不是为了学习金融知识，而是为了判断交易、持有、切换、配置或验证逻辑是否变化。
- 好答案必须回答“为什么现在重要”：关键催化是什么，如何传导到价格/业绩/估值/资金，标的是核心受益还是边缘受益，结论在什么时间区间有效。
- 差答案常见特征是信息很多但密度低，像资讯拼接或通用诊股模板；这种答案不能因为篇幅长、表格多、指标多而高分。
- 技术面、资金面、K 线和均线可以作为辅助，但不能替代题材、业务、业绩、估值、供需、客户、订单和政策等核心逻辑。
- 如果关键资料需要调研纪要、研报全文、专业数据库或公司交流材料，答案要么找到，要么明确说明来源限制；不能用浅层搜索和泛泛客户名单硬答。

## 先识别标的交易风格

评分前先判断答案是否按标的/问题风格选对分析主轴：

| 场景 | 好答案主轴 | 低分信号 |
|---|---|---|
| 热点/题材票 | 题材由来、发酵时间、级别、持续性、核心/边缘地位、补涨空间，再补技术和资金 | 只讲技术指标、资金流或财务概况 |
| 机构/价值票 | 商业模式、业务增长、业绩预测、估值分位/可比公司、风险和安全边际 | 只列财务历史或短期走势 |
| 基金/ETF | 历史收益、回撤、夏普、同类排名、指数对比、前十大持仓、持仓风格和用户匹配 | 只介绍基金经理或近期涨跌 |
| 宏观/资产配置 | 关键变量、时间区间、情景推演、配置建议和风险阈值 | 资讯汇总，没有私人投顾式判断 |
| 消息面/近期资讯 | 严格时间窗口、最新且重要的政策/公告/价格/订单/资金变化 | 旧消息、背景科普、无关小消息凑数 |
| 对比/切换 | A/B 的核心差异、产业地位、业务纯度、估值、确定性、赔率和切换条件 | 分别分析两个标的，不回答是否切换 |
| 个人化推荐/KYC | 用户画像、风险目标、持仓成本、期限、资金规模、情绪处境 -> 产品/标的池 -> 仓位和动作 | 直接给热门股票/ETF、通用投顾模板、无画像却声称“适合你” |
| 亏损/迷茫/深套 | 先降风险和重建决策纪律，再讨论机会；给分步持有/减仓/补仓条件 | 把情绪困境误判为短线选股需求，推荐抓反弹或高波动主题 |

## 好答案的最小闭环

高分答案通常同时具备：

1. **关键事实**：找到了真正影响当前交易的政策、公告、价格、订单、客户、业绩、估值或资金证据。
2. **传导机制**：说明事实如何影响供需、利润、估值、风险偏好或资金选择。
3. **标的定位**：判断标的是龙头/跟随、核心/边缘、直接/间接受益、价值/成长/题材/周期。
4. **量化参照**：给出必要的涨幅、价格变化、收入占比、客户占比、PE/PB、历史分位、同类排名、回撤或情景阈值。
5. **决策语言**：给出短线/中线/长线分层结论、观察条件、买卖/切换/配置建议和主要风险。

缺少其中 2 个以上，通常不能高于 60 分（六档制“基本满足”档）；缺少核心事实或标的定位时，优先检查质量标签。

## 差答案判别信号

- **低密度长答案**：答案很长，但核心结论、关键证据和交易含义很少。
- **重复解释表象**：反复解释“冲高回落”“资金流出”“板块上涨”，没有回答资金为什么这么做。
- **方法错位**：中长线问题用短期技术面，题材票用普通财务模板，价值股用短线情绪，宏观资产用新闻稿。
- **旧信息冒充消息面**：消息面问题给出几个月甚至几年前的背景，忽略最近几天/本月的新催化。
- **浅来源硬答深问题**：客户占比、供应链份额、隐含资产、调研纪要类问题，只用公开搜索或公司简介硬凑。
- **没有“不知道”的边界**：确实没有重大消息或公开占比时，不直接说明来源限制，反而堆砌无关材料。
- **不懂用户的推荐**：用户问“适合我”时，没有用历史提问、画像、持仓或当前自述，只给看似专业的通用标的。
- **高风险默认推荐**：画像不明或普通用户场景下，默认推荐窄行业、高波动主题 ETF/股票，却没有仓位和适用人群边界。
- **情绪场景误判**：用户说迷茫、买什么都亏、快腰斩时，答案直接进入短线策略、技术筛股或补仓建议。
- **推荐不稳定**：同一用户同类问题多次推荐完全不同，且没有市场变化、画像变化或假设变化解释。

## 图片样例提炼的强判分锚点

- 算力租赁上涨：好答案不仅说 AI 需求，还抓住近期政策、服务器涨价、租金/供需量化和产业链传导。
- 基金能不能买：好答案要回答“为什么适合/不适合你、什么时候买、买多少、看什么风险”，而不只是历史表现。
- CPO/光模块价值股：好答案要讲下游需求、客户结构、行业地位、业绩确定性、估值和资金偏好；不能只做财务和技术分析。
- 油气板块强而个股没涨：好答案要区分油气开采、海工/FPSO、订单周期、业务纯度和资金选择理由。
- 光纤题材切换：好答案要量化比较题材纯度、产业地位、业绩确定性和资金抱团；不能反复解释原标的冲高回落。
- 避险资产对比：好答案要讲现金流资产和制造业竞争力资产的本质差异，不只比行业、估值和波动。
- 隐含资产重估：好答案要识别市场炒作的真正原因，如持有资产价值接近或超过自身市值，而不是只按过去业绩估值。
- 中长线持有：好答案要聚焦 2-3 年业务空间、客户、国产替代、盈利质量、估值和风险；短期 MACD/K 线只能辅助择时。
- 最近三天资讯：如果无重大消息，先明确说没有发现重大消息，再解释涨跌可能来自资金/情绪/技术，不要把普通波动包装成大新闻。
- 指数突破推演：常规均线和支撑压力只能及格；更好答案应给情景路径、触发条件、关键点位和概率/风险说明。
- 推荐两只适合我的 ETF：好答案先看风险偏好、持有期限、资金和波动承受，再决定核心宽基/防守增强/行业卫星；直接给医疗、5G 等窄主题高波动 ETF 不能高分。
- 当前宏观环境怎么投：好答案先判断宏观环境，再映射到仓位、资产和期限；“标准资产配置说明书”如果解释不了为什么现在这样配，只能中低分。
- 20 万结合目标风险推荐股票：好答案要有核心/卫星、单票上限、筛选标准、买入/持有/卖出规则；只给概念或热股不够。
- 弱复苏、低通胀、利率下行选四个行业中的两个：必须给历史类似阶段表现、估值分位和盈利确定性；思路高级但关键数据没给，不能高分。
- 市场风险冲击算力租赁并结合风格推荐：必须完成“风险 -> 短中期冲击 -> 结合用户风格推荐标的/仓位/区间”的完整回答，不能只做风险分析。
- 稳增长周期板块优先级：必须比较启动顺序、弹性、持续性和回撤，并把历史验证转成当前配置顺序。
- 短期反弹后分歧阶段仓位控制：好答案先用上涨/下跌家数、涨跌停、成交或情绪定义阶段，再推导仓位和科技成长/资源品的核心卫星结构。
- 深套个股割肉还是加仓：好答案拆政策底、市场底、基本面底和个股风险，给补仓/减仓条件；过度确定触底时间或直接鼓励加仓要重扣。
- 我适合投资什么股票：这是私人投顾感测试。好答案利用历史提问和画像判断适合的股票类型；无画像时说明不足并追问或分层，不编造。
- 我很迷茫买什么都亏：这不是普通荐股。好答案应先建议降频、降仓、复盘、分散和建立筛选纪律，再给低风险框架或长期配置路径。
