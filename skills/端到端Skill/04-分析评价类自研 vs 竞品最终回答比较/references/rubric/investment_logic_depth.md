# `investment_logic_depth` 投资逻辑深度

判断答案是否讲清“为什么这件事影响投资决策”，而不是停留在现象和资料拼接。

关注点：
- 是否提炼核心驱动：政策、供需、价格、业绩、商业模式、资金偏好、风险偏好
- 是否完成逻辑链：事实/事件 -> 传导机制 -> 公司或资产含义 -> 投资判断
- 是否区分表面现象和本质原因，例如“资金没选它”背后的业务纯度、筹码、赛道、核心/边缘地位
- 是否能指出个股不同投资逻辑，做到“千股千评”
- 是否解释逻辑是否顺、估值是否便宜、空间和持续性
- 是否解释资金为什么选择或放弃某个标的，而不是只说“资金流入/流出”
- 是否识别近期价值重估、隐含资产、客户结构、订单周期、题材纯度等真正驱动

常见失败模式：
- 只有财务、技术、资金、消息四栏模板，没有核心投资论点
- 只说涨跌和资金流，不解释资金为什么这样选择
- 对价值股只做财务分析，不说明商业模式和估值逻辑
- 对题材股只讲技术面，不讲题材级别、发酵和空间
- 把“公司不错/行业不错”当成投资逻辑，没有说明当下赔率、确定性和催化

## 与其他规则的关系

- 与 `method_fit` 在千股千评场景有交叉，但职责不同：本维度负责"投资论点是否深入"（是否讲清核心驱动、传导机制、赔率和确定性），`method_fit` 负责"分析方法是否适配"（是否按标的类型选对了分析主轴）。方法对但论点浅，属于本维度失分；论点深但方法错位（如题材票用价值股框架），属于 `method_fit` 失分。

## 适用性判断

- **始终 relevant**。分析评价类问题的主干就是投资逻辑。
