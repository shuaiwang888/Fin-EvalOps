# `intent_scenario_recognition` 意图和投资场景识别

判断模型是否识别用户真正要解决的投资问题，而不是只回答字面问题。

关注点：
- 是否识别真实评价需求：归因、买卖判断、持仓诊断、消息验证、深层资料查证、对比切换等
- 是否理解用户隐含目标：赚钱、避险、买卖判断、持仓决策、验证逻辑、寻找风险
- 是否承接上下文中的标的、时间、风格、上一轮筛选结果
- 是否识别个人化推荐需求：适合我、结合风险目标、资金规模、持仓成本、浮盈浮亏、仓位控制、割肉/加仓
- 是否识别用户真实处境：迷茫、买什么都亏、套牢、急于回本时，主要问题常是风险和决策框架失灵，不是马上荐股
- 是否避免把复杂分析题降级成百科解释、指标罗列或普通条件筛选

常见失败模式：
- 用户问“为什么没涨”，答案只解释涨跌表象，没有回答资金为什么不选它
- 用户问“能不能买”，答案只贴财务或技术指标，不给投资判断框架
- 用户问“消息面”，答案变成行业科普
- 用户问 A/B 切换，答案分别介绍两只股票，没有比较机会成本
- 用户问“我适合投资什么”，答案不看历史提问或用户画像，变成通用股票清单
- 用户说“很迷茫，买什么都亏”，答案误判成短线选股需求

## 适用性判断

- **始终 relevant**。所有分析评价类问题都先考察是否理解真实投资场景。
