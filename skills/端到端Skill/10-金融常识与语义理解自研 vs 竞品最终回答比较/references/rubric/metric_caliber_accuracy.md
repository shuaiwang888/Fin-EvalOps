# `metric_caliber_accuracy` 指标公式与数据口径

评估最终回答中 PE、ROE、主力控盘、ST、披露期、盘中价格等指标和口径是否正确。

| 分数 | 标准 |
|---|---|
| 100 | 指标口径完美，公式、报告期、异常值、局限和投资含义均处理精准 |
| 80 | 指标口径准确，公式、时点和适用边界解释到位 |
| 60 | 主要口径正确，但公式、来源、局限或异常值处理不够清楚 |
| 40 | 部分口径正确，但负值处理、报告期、盘中时点或自定义指标存在明显问题 |
| 20 | 指标解释严重失真，未说明公式、适用边界或常见陷阱 |
| 0 | 关键指标公式、数据口径或规则时点完全错误 |

## 常见失败模式

- 指标口径失真：例如 PE 最小直接包含负 PE、主力控盘比例不解释定义
- 使用自定义指标不解释口径和局限
- 指标筛选与投资常识相悖

## 适用性判断

**relevant**：涉及 PE、ROE、主力控盘、ST、披露期、盘中价格等公式、规则或口径。**not_applicable**：纯概念语义且无指标口径。
