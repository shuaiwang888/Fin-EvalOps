# `forced_mapping_or_entity_boundary_error` 强行映射或实体边界错误

上限：`50`

触发条件：
- 对海外巨头、产业标杆或题干描述进行 A 股映射时，强行给出业务模式明显不匹配的公司作为核心对标。
- 将代工厂误判为品牌厂，将下游应用误判为上游材料，将概念弱关联误判为主营核心，或把用户明确排除的业务类型纳入核心答案。
- NER/Linking 或行业边界识别错误导致遗漏用户关注的核心标的，反而给出低知名度、弱相关或错误类别标的。

注意事项：
- 本规则不惩罚谨慎地指出"没有完全对标"。相反，能清楚说明差异并给出分维度可比公司的答案应加分。
- 若同时存在关键事实错误，可与 `hard_time_or_fact_error` 同时考虑，最终取更低上限。
