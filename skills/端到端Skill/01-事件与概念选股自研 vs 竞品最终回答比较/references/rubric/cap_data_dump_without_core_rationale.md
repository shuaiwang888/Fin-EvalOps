# `data_dump_without_core_rationale` 数据堆砌无核心论证

上限：`55`

触发条件：
- 答案主要输出股票列表、表格或数据，没有解释核心受益逻辑
- 对事件/主题/概念题只给代码、涨跌幅、成交额、市值、概念纳入原因等字段，未说明个股与题材的真实挂钩方式
- 对用户需要决策的题目没有核心票、边缘票或梯队划分，导致用户仍需自行逐个排雷确权

## 注意事项

若触发此封顶规则，根因标签应优先归为 `reasoning` 层（如 `broken-causal-chain`、`no-ranking-criterion`），而非 `composition` 层的 `data-dumping`。数据堆砌本身只是表象，其根因通常是投资逻辑推导失败。
