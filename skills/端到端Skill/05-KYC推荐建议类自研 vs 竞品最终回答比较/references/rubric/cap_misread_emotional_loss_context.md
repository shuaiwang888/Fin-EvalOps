# 质量标签：`misread_emotional_loss_context`

## 触发条件

用户表达明显亏损、套牢、迷茫、信心受挫或急于回本，但最终回答把问题误判为普通荐股或短线交易机会，并给出不适合该处境的高风险建议，例如：
- 直接推荐短线、抓反弹、追热点或高波动主题。
- 鼓励加仓但没有仓位边界、证伪条件和风险承受说明。
- 忽略用户情绪和亏损背景，只输出策略模板。

## 分数上限

`score_ceiling = 50`

## 不触发条件

- 答案识别亏损/迷茫状态，并优先给降风险、复盘、仓位和观察条件。
- 用户只是普通风险偏好表达，没有亏损或情绪困境信号。

- `risk_boundary_control`
