# `recommendation_stability` 推荐稳定性与变化解释

判断同类 KYC 推荐在相近用户约束和市场约束下是否保持稳定的推荐原则；若推荐发生变化，是否解释变化来自市场、目标、风险、持仓、约束或产品数据，而不是随机换答案。

关注点：
- 是否有稳定的筛选原则，例如风险等级、期限、资金规模、核心-卫星结构、产品池边界和证伪条件。
- 多次问“适合我的 ETF/股票/配置”时，推荐逻辑是否前后一致。
- 推荐变化是否说明原因：市场阶段改变、用户目标改变、风险承受改变、持仓改变、产品数据改变。
- 是否避免每次给完全不同的热门产品、主题或股票，却没有任何新依据。
- 是否在答案中沉淀可延续的私人投顾体验。

常见失败模式：
- 用户反复问“推荐两只适合我的 ETF”，每次给不同产品且无解释。
- 上一次按稳健配置，这一次突然推荐高波动主题，没有约束变化或市场变化支撑。
- 推荐原则摇摆：有时按收益排名，有时按热点，有时按行业故事，缺少一致框架。
- 答案说“适合你”，但看不出任何可复用的适配标准。

## 适用性判断

- **relevant**：输入问题包含历史推荐变化、用户反馈“每次不一样”或稳定性诉求。
- **supplementary**：普通“适合我”推荐，可用于检查是否给出可延续原则。
- **not_applicable**：一次性事实查询或没有推荐延续要求的场景。
