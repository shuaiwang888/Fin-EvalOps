# `composition_credibility` 表达可信度

判断最终回答是否清楚、克制、可信，并能让用户理解推荐依据和边界。

关注点：
- 是否结构清晰，先结论再理由，再行动和风险。
- 是否避免模板化、泛泛而谈、空洞免责声明。
- 是否避免过度啰嗦、计算细节过多、技术指标堆砌。
- 是否避免伪专业、主观断言、无依据的确定表达。
- 是否让用户感到建议可理解、可复核、可执行。
- 是否先结论、再依据、再动作，避免用长篇计算过程压过主判断。

常见失败模式：
- 看似完整但像标准投顾说明书，缺少针对用户的判断。
- 文字很长但主结论不清楚。
- 指标和数据很多，但没有形成决策框架。
- 语气过度自信或过度保守，导致建议不可用。
- 结构规整但每一段都能套到任何用户，缺少“为什么适合你/为什么现在这样做”。

## 适用性判断

- **始终 supplementary**。
