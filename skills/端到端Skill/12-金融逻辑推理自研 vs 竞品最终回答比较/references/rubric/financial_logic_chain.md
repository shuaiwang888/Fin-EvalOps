# `financial_logic_chain` 金融逻辑链（建议权重 25）

判断答案是否把金融事实、市场驱动、个股属性、资金/技术/基本面证据推导成完整投资逻辑。

关注点：
- 事实与指标不是孤立出现，而是能解释“为什么影响未来表现”；
- 逻辑链至少覆盖：问题意图 → 决策对象 → 驱动因素 → 证据 → 结论；
- 个股判断需要落到业务暴露、景气变化、资金承接、技术状态、估值安全边际或催化节奏；
- 短线题要解释题材发酵、赚钱效应、资金切换和持续性；
- 中长期题要解释增长、盈利、竞争格局、估值和风险的关系；
- 操作建议题要说明条件、触发点和不成立情形。

常见失败模式：
- 只列技术面、资金面、财务指标或公告，没有投资逻辑；
- 有宏观或行业判断，但没有落到个股为什么更值得选择；
- 把低估值、上涨、资金流入等单一事实直接等同于“有潜力”；
- 推理链中关键环节断裂，例如从热点直接跳到买入建议；
- 预测方向没有说明成立条件。

## 适用性判断

- **始终 relevant**。金融逻辑推理任务均考察该维度。
