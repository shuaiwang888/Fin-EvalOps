# `logical_decomposition` 逻辑拆解能力（权重 10）

判断答案是否将复杂的多步/多条件查询正确拆解为可执行的子步骤。

关注点：
- 条件拆解：复合条件（如"连续两日下跌>4000家→买入→次日卖出"）是否被分解为依次执行的子查询
- 步骤完整性：拆解后的每个子步骤是否被执行，中间结果是否正确传递到下一步
- 逻辑链闭合：从原始查询到最终结果的逻辑链是否完整无断裂

本维度只看最终回答是否呈现了正确的任务拆解、条件传递和逻辑闭环；不得依据不可见过程推断拆解质量。

常见失败模式：
- 无法拆解复合条件：面对"连续两个交易日全市场下跌家数超过4000家"的条件组合直接报错或返回空结果
- 跳步或简化：将多步回测简化为单步查询，丢失了关键的条件筛选逻辑
- 中间结果断裂：第一步查询结果未能正确传递到第二步，导致后续计算基于错误的中间值
- 多指标提取时未分解：同时提取多个指标+计算衍生指标+对比+阈值筛选的复合任务被部分执行

## 适用性判断

- **relevant**: 题目涉及多步/多条件复合查询（如"连续N日下跌后买入"、"先筛选再计算再对比"）
- **supplementary**: 题目为单步查询但需拆解为子任务
- **not_applicable**: 简单单步取数查询（如"某只股票的收盘价"）
