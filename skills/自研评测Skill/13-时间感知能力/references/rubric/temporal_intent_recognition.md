# `temporal_intent_recognition` 时间意图识别

识别用户问题中的显式/隐式时间意图。

| 分数 | 标准 |
|---|---|
| 100 | 完美识别所有显式和隐式时间意图，包括跨市场时区和交易日差异 |
| 80 | 准确抽取时间词、市场/标的、自然日/交易日/报告期语义，并说明需要的锚点 |
| 60 | 基本识别时间意图但个别时间词解析不够精确 |
| 40 | 识别到时间相关，但遗漏关键锚点或未区分自然日/交易日 |
| 20 | 仅识别到部分时间线索但遗漏关键时间语义 |
| 0 | 完全按普通行情/分析题处理，忽略时间词 |

## 适用性

任何包含相对时间、日期、周几、交易日、最新、今天、去年、年中、截至等表达的问题。
