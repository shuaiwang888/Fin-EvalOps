# `tool_usage` 工具使用合理性

评估链路是否正确使用工具核验时间、交易日历和数据时点。

| 分数 | 标准 |
|---|---|
| 100 | 工具使用完美，所有时间相关核验完整，输入参数精确，输出解读正确 |
| 80 | 调用合适工具，输入包含正确市场/代码/日期/报告期，正确读取返回日期 |
| 60 | 工具使用合理但效率不高或有个别遗漏 |
| 40 | 工具方向正确但输入或读取不完整 |
| 20 | 工具选择明显错误，关键时间核验步骤缺失 |
| 0 | 应查交易日历/行情日期却没查，或查了错误市场、错误日期、错误报告期 |

## 适用性

需要外部交易日历、行情、公告、财报、分红、跨市场数据或最新状态的问题。
