# `period_disclosure_mapping` 财报期间映射

正确处理财报、分红、年度/季度/年中等报告期和披露期。

| 分数 | 标准 |
|---|---|
| 100 | 财报、分红、报告期和披露期映射完美，所有年份和期间边界清晰 |
| 80 | 区分自然语言年份、财政/报告期、披露日期和最新可得数据；缺数据时先说明缺口再给替代 |
| 60 | 报告期映射基本正确但个别边界说明可优化 |
| 40 | 报告期方向正确但披露期或替代口径说明不完整 |
| 20 | 报告期或披露期映射出现严重影响结论的错误 |
| 0 | 把披露日/分红日/报告期混为一谈，或把"去年"私自改成更早年份 |

## 适用性

涉及去年营收、今年一季报、年中分红、某年报、最新财报、同比/环比期间。
