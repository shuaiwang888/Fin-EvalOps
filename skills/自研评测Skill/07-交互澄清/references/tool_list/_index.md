# 工具评分参考

当前 self_judge 输入中可能出现以下工具。评分时根据实际 `tools` 清单和 `chain` 调整。

## Search

用于检索交易规则、公告、新闻、公开资料、公司事件、市场解释。适合：
- 科创板盘后交易规则、北交所权限、国债逆回购计息、分红税费等规则核验。
- 最新公告、业绩预告、季报、公司事件。

扣分点：需要规则核验却未搜索；搜索到资料但没有进入最终答案；引用旧资料解释最新问题。

## FinQuery

用于结构化行情、股票实体、资金、财务、筛选条件查询。适合：
- 个股行情和技术位、候选股筛选、资金流、股息率、财务指标。
- 错别字标的的候选确认，但不能单独决定低概率实体。

扣分点：错别字/异常代码只信单次结果；筛选条件口径不透明；查询时间窗与问题不匹配。

## CustomerServiceFAQ

用于同花顺产品、交易规则、撤单、权限、账户、客服类说明。适合：
- 撤单失败、权限开通、ETF/科创板/北交所规则、交易时间。

扣分点：客服规则问题不用规则类工具；答案把规则说错。

## AccessingFullText

用于读取公告、研报、全文材料。适合：
- 业绩预告、正式季报、分红公告、权限规则文件等需要原文的场景。

扣分点：只用摘要导致关键事实错漏。

## BackTest / Forecast

用于明确要求历史统计、回测或预测模型的场景。交互澄清中通常不是首选；若用户要求"年底翻倍"或"涨到目标价"，不能把 forecast 输出当确定结论。

## SearchImage

用于用户提供图像或需要图像证据的场景。07 文档本身的图片批注用于评测参考，不代表被评测模型必须调用 SearchImage。

## SaveUserProfile

用于长期用户偏好、持仓、风险偏好等记忆场景。若输入链路显示用户长期信息可用但未使用，可作为 `context_continuity` 或 `tool_usage` 证据。

## CodeInterpreter

用于复杂计算、筛选后复核、表格处理。普通交互澄清不应滥用。
