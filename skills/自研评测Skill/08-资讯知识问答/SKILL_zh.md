# 资讯知识问答评测协议

用稳定协议评测我方在"资讯知识问答 / consultation-and-qa"场景下的最终回答。评分以用户问题和 `text_answer` 为主锚点；规划链路只用于工具使用与根因归因，不为最终答案隐藏加分。

## 适用范围

当用户问题要求模型解释、查询、比较或判断金融资讯、政策、监管动态、产业事件、公司进展、市场异动原因、市场传闻或调研纪要相关信息时使用本协议，例如：
- 最新政策、监管、产业数据或公司事件的梳理与评价。
- 某新闻、政策、宏观事件或产业事件对 A 股行业/标的的影响。
- 某公司项目、产能、海外建厂、新产品、供应链进展是否有新变化。
- 某板块、主题或大盘当天/近期异动的主要原因。
- 市场小段子、金融大V文章、调研纪要、官媒截图等非标准资讯对股价或热点的解释。
- 多个热门方向的新闻密度、政策层级、产业落地进度横向比较。

不适用于纯行情查询、纯财务指标查询、无资讯理解要求的条件选股、普通客服问答或泛泛投资建议。

## 期望输入

每次评测获取以下材料：
- 用户问题。
- 我方最终答案，以 `text_answer` 为评分主锚点；如需看图表/截图/markdown 呈现，可辅助读取 `answer`。
- 完整对话消息或规划链路，用于评估工具使用与根因。

## 执行协议

0. **分析题目与分配动态权重**
   阅读 [references/rubric/_index.md](references/rubric/_index.md)，仅根据用户问题判断各维度适用性：
   - `relevant`：本题关键判断依据。
   - `supplementary`：有参考价值但非核心。
   - `not_applicable`：本题不适用，评分时跳过。
   动态权重总和必须等于 100。`not_applicable` 维度权重为 0。

   同时阅读 [references/golden_cases/_index.md](references/golden_cases/_index.md) 和 [references/golden_cases/image_annotation_anchors.md](references/golden_cases/image_annotation_anchors.md)。若用户问题命中专家案例或同类语义，必须把对应 hard checks 纳入核验；未命中时也要使用跨案例判分锚点。

1. **盲评打分**
   只对 `relevant` 和 `supplementary` 维度评分，跳过 `not_applicable` 维度。
   以最终答案为准，不因规划链路里"想到了"但答案没写出而加分。
   每个维度只输出 `raw_score`，取值为 0/20/40/60/80/100。

2. **诊断根因**
   阅读 [references/root-cause/_index.md](references/root-cause/_index.md)，按需读取对应 L1 文件。
   阅读 [references/tool_list/_index.md](references/tool_list/_index.md)，再评分 `tool_usage`。
   根因只能从活跃维度中选择。优先解释最低分维度；若触发强封顶规则且它更能解释总分下降，则以封顶违规维度作为主根因。

3. **应用封顶规则**
   阅读相关封顶规则文件。封顶只影响最终分数上限，不替代维度评分。
   多个封顶同时触发时取最低上限。隐藏规划不能解除最终答案触发的封顶。

4. **序列化输出**
   阅读 [references/output-schema_zh.md](references/output-schema_zh.md)。
   先输出结构化 JSON，再附简短自然语言评审。

## 保守评分

- 不计算 `weighted_points`、`absolute_score_pre_cap` 或 `final_score`，这些由调用方代码处理。
- "最新、近两周、截至某日、当天、这周"等表达必须严格核对时间范围。
- 信息密度高不等于好答案。若没有核心事件、时间点、证据类型、影响链条和标的/行业映射，只能按素材堆砌扣分。
- 对市场小段子、调研纪要、大V文章、官媒截图等来源保持来源类型敏感：这些材料常决定时效性和重点抓取，但也必须区分传闻、确认事实和主观解读。
- 对非公开/半公开信息要审慎表达，允许指出"需核验"或"传闻口径"，不能把未证实内容写成确定事实。

## 安全护栏

- 严肃对待事实硬错：关键年份、政策历史定位、数据口径、项目进展、量产时间、公司/产品边界错误会显著封顶。
- 严肃对待时间边界：不得把未来数据、旧公告或长期主线混入"最新/近两周/当天"答案。
- 严肃对待用户真实意图：用户常表面问"是什么/为什么"，实际要"影响、受益标的、怎么判断、是否可持续"。
- 惩罚模板化回答：基本面/技术面/资金面/消息面四段式若没有抓到真实催化剂，应低分。
- 惩罚宽泛标的罗列：必须给出主线、催化剂、受益环节、核心标的和边界。
- 对横向比较题要求收敛结论：新闻密度、政策层级、产业落地、概念热度等维度必须可比较，不能三段素材拼接。
