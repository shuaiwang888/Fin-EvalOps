# 工具与来源类型总览

本 skill 不限定实际系统必须有同名工具；评测时根据规划链路中的工具能力和输出判断是否覆盖了需要的来源类型。

| 工具/来源类型 | 适合场景 | 评分关注点 |
|---|---|---|
| `Search` / 新闻搜索 | 最新政策、新闻、市场异动、公司进展 | 是否限定时间、关键词是否命中核心催化、是否覆盖权威来源 |
| `FinQuery` / 金融数据查询 | 行情、板块、个股、财务、销量、估值、指标 | 数据口径、证券实体、时间区间是否正确 |
| `AccessingFullText` / 全文读取 | 政策原文、公告、研报、新闻全文、大V文章 | 是否只看摘要；是否提取核心段落 |
| `SearchImage` / 图像搜索或截图识别 | 官媒截图、图表、社交媒体截图、文章图片 | 图片是否用于证据；是否转述准确 |
| `CompanyAnnouncement` / 公告查询 | 项目进展、投产、定点、订单、股权事项 | 是否用公告核验硬事实 |
| `ResearchMemo` / 调研纪要 | 产量、客户、扩产、内部进展、业绩拆分 | 是否标明纪要/交流属性和不确定边界 |
| `MarketChatter` / 市场小段子 | 盘中热点、涨停原因、传闻催化 | 是否当作线索而非确定事实；是否交叉验证 |
| `InfluencerArticle` / 金融大V文章 | 市场主因、用户心理、重点筛选 | 是否借助观点抓重点，同时保持来源边界 |
| `CodeInterpreter` / 数据处理 | 多数据表、图表、统计口径整理 | 是否用于必要的清洗、对比和口径计算 |

## 工具使用评分要点

- 强时效问题必须体现时间过滤或最新来源核验。
- 硬事实应尽量用官方、公告、权威新闻交叉验证。
- 市场异动题如果没有覆盖当天催化、小段子或大V/官媒线索，`tool_usage` 不应高分。
- 使用非标准来源时，若没有再核验或未标注边界，工具使用和事实证据都要扣分。
