# 六档原始分

所有维度使用同一六档 raw_score：

| raw_score | 含义 |
|---:|---|
| 0 | 完全失败、拒答、跑题，或输出严重误导 |
| 20 | 只触及边角，核心要求大部分缺失 |
| 40 | 方向部分正确，但关键事实、时间、证据、主线或落地明显不足 |
| 60 | 基本可用，但存在一个或多个显著短板 |
| 80 | 表现良好，覆盖主要要求，仅有轻微遗漏 |
| 100 | 专家级完成，事实、时效、证据、判断和表达均无明显可挑剔之处 |

评分要保守。资讯知识问答不是"写得多就高分"，必须看是否抓到正确时间窗口、核心事件、可靠证据和金融落地。
