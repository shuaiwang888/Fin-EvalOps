# `financial_term_understanding` 金融术语/规则理解

评估对金融术语、交易规则、市场黑话和财务概念的理解是否正确。

| 分数 | 标准 |
|---|---|
| 100 | 金融术语、规则和黑话理解完美，解释精准且可复核 |
| 80 | 术语和规则理解准确，解释清晰，仅有极轻微不足 |
| 60 | 关键术语理解正确，但个别规则或黑话解释不够精确 |
| 40 | 术语理解大致可接受但有明显偏差或定义不准确 |
| 20 | 关键术语概念出现实质性错误，或混淆基本规则 |
| 0 | 核心金融术语或交易规则完全理解错误 |

## 常见失败模式

- 规则硬错：例如集合竞价 9:20 当成已成交量、最新季度 ROE 使用未披露报告期
- 对 PE、ROE、ST、集合竞价等基础规则，硬性错误应重扣

## 适用性判断

涉及金融术语、交易规则、市场黑话、财务概念时 relevant。
