# `explicit_instruction_completion` 显式指令完成

评估主指令是否被完整执行。始终考察。

| 分数 | 标准 |
|---|---|
| 100 | 完整执行主指令和关键约束，答案类型、焦点、证据均匹配 |
| 80 | 主指令完成，少量约束或证据补充不充分 |
| 60 | 大方向相关，但主指令执行不完整，用户仍需追问 |
| 40 | 只完成相关任务，未真正完成用户要求的任务类型 |
| 20 | 大部分答非所问，仅有零散相关数据 |
| 0 | 完全没有回应主指令或对象错误 |

## 常见失败模式

- 用户要求解释原因，答案只给上涨事实和数据
- 用户要求核实/截止/重新看，答案沿用旧数据
- 用户要求比较或区别，答案只分别介绍不比较

## 适用性判断

始终 relevant。主指令是否被完成是所有题目的核心判断。
