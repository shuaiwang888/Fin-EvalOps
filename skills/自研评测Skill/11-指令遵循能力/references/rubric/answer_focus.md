# `answer_focus` 答案焦点

评估是否围绕主问展开，而非数据堆砌或跑题。始终考察。

| 分数 | 标准 |
|---|---|
| 100 | 焦点完美，每个信息片段都服务主问，无任何偏离 |
| 80 | 焦点清晰，围绕主问展开，信息密度合理 |
| 60 | 基本围绕主问，但部分内容不够聚焦 |
| 40 | 有部分相关内容但焦点模糊，被次要信息稀释 |
| 20 | 重点明显偏离用户要求，大量无关内容 |
| 0 | 答案完全跑题，与用户主问无关 |

## 常见失败模式

- 用户问原因，答案先堆5行数据表再写一句话
- 用户问定义，答案先给行情页面再解释
- 关键结论藏在模板化结构末尾

## 适用性判断

始终 relevant。是否围绕主问展开。
