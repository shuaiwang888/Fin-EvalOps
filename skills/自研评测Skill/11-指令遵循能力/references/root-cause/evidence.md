# `evidence` — 证据收集

| L2 | 说明 | 典型受影响维度 |
|---|---|---|
| `evidence-not-causal` | 原因题只收集现象数据，缺少驱动证据 | necessary_information_completeness |
| `definition-evidence-missing` | 定义题缺少概念边界和通用口径 | task_type_alignment |
| `constraint-evidence-missing` | 未收集用户指定对象或时点的数据 | constraint_coverage |
| `irrelevant-evidence-dominates` | 大量相关但不回答主问的信息挤占答案 | answer_focus |
