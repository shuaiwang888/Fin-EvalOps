# `evidence` — 证据收集

| L2 | 说明 | 典型受影响维度 |
|---|---|---|
| `driver-evidence-missing` | 缺少热点、催化、资金承接或上涨原因证据 | market_driver_identification |
| `business-exposure-missing` | 多股比较缺少业务占比、资源属性或弹性证据 | comparison_and_ranking |
| `one-sided-evidence` | 只收集技术面或公告，忽略基本面/资金/市场情绪 | evidence_to_conclusion |
| `risk-evidence-missing` | 缺少回撤、估值、追高、流动性等风险证据 | scenario_risk_reasoning |
