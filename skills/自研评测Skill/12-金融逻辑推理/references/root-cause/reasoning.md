# `reasoning` — 投资逻辑推导

| L2 | 说明 | 典型受影响维度 |
|---|---|---|
| `indicator-as-conclusion` | 把 PE、均线、资金流等指标直接当结论 | evidence_to_conclusion |
| `driver-chain-broken` | 驱动因素到个股影响的链条断裂 | financial_logic_chain |
| `market-hotspot-missed` | 短线题忽略主线、情绪和资金承接 | market_driver_identification |
| `ranking-criterion-missing` | 多股选择没有统一排序标准 | comparison_and_ranking |
| `scenario-missing` | 预测或操作建议没有情景分支 | scenario_risk_reasoning |
| `overconfident-forecast` | 对涨停、上涨或买卖给确定性承诺 | scenario_risk_reasoning |
