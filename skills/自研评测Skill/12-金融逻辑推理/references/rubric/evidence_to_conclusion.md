# `evidence_to_conclusion` 证据到结论连接

评估数据、新闻、公告、资金是否充分支撑结论。始终考察。

| 分数 | 标准 |
|---|---|
| 100 | 每一个结论都有精准证据支撑，证据链完整可追溯 |
| 80 | 证据充分，与结论连接清晰，逻辑自洽 |
| 60 | 证据基本支撑结论，但个别连接不够紧密 |
| 40 | 有部分证据但连接不紧密，存在逻辑跳跃 |
| 20 | 关键结论缺少证据，或使用了明显不相关的数据 |
| 0 | 结论完全无证据支撑或证据与结论矛盾 |

## 常见失败模式

- 给结论但不展示数据来源
- 证据是通用资讯但结论是针对具体个股
- 多个证据之间互相矛盾但不说明

## 适用性判断

始终 relevant。证据是否支撑结论。
