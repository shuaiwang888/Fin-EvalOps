# `scenario_risk_reasoning` 情景与风险推演

评估是否给出多情景分析和风险考量。

| 分数 | 标准 |
|---|---|
| 100 | 多情景推演完整，风险量化清晰，有明确的应对策略和验证节点 |
| 80 | 情景分析到位，风险考量充分，有明确的触发条件 |
| 60 | 给出了基本风险考量但情景分析不够全面 |
| 40 | 有基本的风险提及但缺少具体情景推演 |
| 20 | 对高风险建议完全无风险提示 |
| 0 | 完全没有风险或情景考量 |

## 常见失败模式

- 追高、明日涨停建议没有任何风险提示
- 只讲好不讲坏，没有下行情景
- 判断给出确定性承诺而非概率表达

## 适用性判断

预测、追高、操作建议、下周/明天题 relevant。
