# `comparison_and_ranking` 个股比较与排序

评估多股选择、推荐、排序是否有统一比较标准和依据。

| 分数 | 标准 |
|---|---|
| 100 | 比较完美，标准统一可复现，所有关键维度覆盖，排序自洽 |
| 80 | 比较标准统一，排序依据清晰，维度选择合理 |
| 60 | 比较基本合理但个别标准或维度不够清晰 |
| 40 | 比较方向大致正确但标准不统一或维度缺失 |
| 20 | 有比较但无统一标准，或排序逻辑严重混乱 |
| 0 | 完全未做比较或排序依据错误 |

## 常见失败模式

- 多股怎么选只看技术面，不比较业务占比、弹性、自给率和风险
- 说"更看好xx"但不说明比较维度
- 排序标准不一致，对不同股票用不同指标

## 适用性判断

多股选择、怎么选、推荐、排序时 relevant；单股题 supplementary。
