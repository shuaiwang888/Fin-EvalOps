# `data_dump_without_insight` 数据堆砌无洞察

上限：`65`

触发条件：
- 对诊断、对比或解释题，只堆砌数据表，没有结论、差异、原因或观察点。
- 用户问增长点、止盈位、是否有主力、比价关系、行业跑赢原因，答案只列原始字段。
- 图表或表格很多，但没有转译为用户可用判断。

不触发情形：
- 用户明确只要求原始数据，且答案准确完整。

与 `presentation_visualization` 的关系：
触发本封顶规则时，`presentation_visualization` 应给低分（数据堆砌本身说明呈现不佳），但不重复扣分——封顶已限制总分上限，维度评分仅反映呈现质量本身。
