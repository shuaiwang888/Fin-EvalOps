# L1: `reasoning`

用于归因事实到影响、传导和策略之间没有闭环。

常见 L2：
- `fact-impact-strategy-gap`：有事实但没有影响和策略。
- `transmission-path-missing`：事件或政策没有传导路径。
- `comparison-without-tradeoff`：多对象比较没有取舍逻辑。
- `strategy-trigger-missing`：情景推演缺少触发条件和应对动作。
- `investment-mapping-gap`：行业或海外厂商分析没有映射到 A 股投资线索。

证据要求：
- 引用最终答案中的事实、影响或策略断点。
- 说明闭环缺失如何影响用户决策。
