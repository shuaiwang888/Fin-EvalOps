# `task_coverage_priority` 子任务覆盖与主次

判断最终答案是否覆盖关键子任务，并按用户决策价值组织主次。

关注点：
- 是否逐一回应用户明确提出的问题
- 是否把主任务放在主线位置，辅助信息不喧宾夺主
- 是否对关键子任务给出足够展开，而不是标题式带过
- 是否在信息不足时说明未完成项和原因
- 是否避免覆盖很多边缘内容却漏掉真正影响判断的核心问题

常见失败模式：
- 关键子任务漏答，例如问“有没有其他股票先例”但没有举例
- 重点发散，行业背景很多，用户要的结论和比较很少
- 覆盖公司或指标很多，但没有聚焦“哪个环节/哪个公司最受益”
- 主次错位，先讲宏观长篇，最后才轻描淡写回答操作

## 与 `intent_decomposition` 的边界

`intent_decomposition` 关注模型是否在规划阶段识别出所有子任务；`task_coverage_priority` 关注最终答案是否真正覆盖并展开这些子任务。若模型识别了子任务但答案遗漏，两个维度都可能扣分，但 `task_coverage_priority` 侧重最终输出的完整性，`intent_decomposition` 侧重拆解的准确性。

## 适用性判断

- **始终 relevant**。
