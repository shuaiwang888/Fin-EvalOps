# `multi_source_evidence_integration` 多源证据整合

判断答案是否把行情、新闻、公告、产业、政策、财务、资金、情绪、舆论等信息整合成统一结论。

关注点：
- 是否使用与题目匹配的信息源组合
- 是否把多源信息串起来，而不是并列罗列
- 是否区分信息与标的/行业的相关度强弱
- 是否将公告、新闻、资金、基本面和交易节奏转化为影响评估
- 是否避免信息拼盘、低关联新闻和浅层资料堆砌

常见失败模式：
- 新闻很多但与核心标的关联弱
- 行情、公告、政策、舆论之间没有形成统一判断
- 只做资料罗列，没有解释为什么这些信息改变投资判断
- 产业链分析没有落到公司、环节、利润或估值
- 用弱相关宏观热点填充 48 小时新闻，却没有服务于核心标的影响评估
- 深度调研缺少市场规模、份额变化、技术路线、产品节奏、客户导入或 A 股映射
- 地缘/政策/行业事件只套模板，没有用指定事件、指定日期或指定公司证据验证

## 适用性判断

- **relevant**：涉及多源信息、新闻公告、产业链、政策、资金、财务、舆论。
- **supplementary**：主要是单一计算或单一交易方案。
- **not_applicable**：纯单步事实或计算。
