# `time_inference_error` 时间推理错误

上限：`45`

触发条件：
- 交易日判断错误：将实际交易日幻觉为非交易日，或将非交易日误认为交易日
- 节假日倒推错误："节前N个交易日"推算为错误的日历区间（如用日历日代替交易日）
- 年份或日期锚定错误：年报披露日期、上市日期等关键时间锚点提取有误
- 时间范围实质偏差：推算的时间区间与正确区间存在实质性偏差，导致后续计算全部失效

> **与 time_inference 维度评分的关系**：触发本封顶规则时，`time_inference` 维度应给最低分（0 或 20）。封顶规则是维度评分的硬约束下限——维度低分确认错误严重性，封顶规则限制该错误对总分的影响上限。两者不矛盾：维度评分反映"错得多离谱"，封顶规则反映"总分最多降到多少"。
