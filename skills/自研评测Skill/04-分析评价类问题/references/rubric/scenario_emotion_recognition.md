# `scenario_emotion_recognition` 场景与情绪识别

判断答案是否识别用户真实投资处境，尤其是浮亏、套牢、腰斩、迷茫、信心受挫、买什么都亏、急于回本等信号。

关注点：
- 是否把“很迷茫、买什么都亏、快腰斩、浮盈/浮亏、套牢”理解为风险和决策状态，而不是普通荐股入口。
- 是否先稳定决策框架：降风险、复盘错误、控制仓位、减少交易频率、分散配置，再谈机会。
- 是否区分情绪安抚和投资建议：情绪回应不能替代仓位、期限、证伪条件和下一步动作。
- 是否避免刺激用户追涨、短线抓反弹、单票重仓或为了回本加大风险。
- 是否有私人投顾感：能承接用户历史和当下处境，让建议像“懂我”而不是冷冰冰模板。

常见失败模式：
- 用户说“很迷茫，感觉买什么都是亏”，答案直接切到短线综合推荐、技术面筛股或强势板块。
- 深套用户问割肉还是加仓，答案急着判断底部或鼓励补仓，没有先拆政策底、市场底、基本面底和补仓条件。
- 对浮盈用户只讲行业基本面，缺少止盈、减仓、持有和回撤容忍条件。
- 安慰很多，但没有把情绪处境转化成降低错误决策概率的行动框架。

## 边界说明

- 与 `user_profile_suitability` 的区分：本维度负责识别情绪状态和风险处境（浮亏、迷茫、套牢等）并给出适配该状态的决策框架；`user_profile_suitability` 负责用户画像数据（风险偏好、资金规模、投资期限等）的识别和使用。情绪状态是动态即时信号，用户画像是相对稳定的属性数据。

## 适用性判断

- **relevant**：浮亏、套牢、腰斩、迷茫、焦虑、急于回本、买什么都亏、持仓成本、私人投顾感。
- **supplementary**：普通推荐、普通配置、普通持有建议。
- **not_applicable**：无个人处境信号的客观分析或资料查询。
