# `evidence_source_quality` 证据来源质量

判断答案支撑材料是否关键、充分、专业，是否使用了适合本题的信息来源。

关注点：
- 行情归因和消息面是否找到关键催化、公告、政策、新闻、价格变化或资金行为
- 价值股分析是否有业务、财务、估值、研报逻辑和风险证据
- 基金分析是否有历史收益、回撤、夏普、同类排名、持仓和风格证据
- 个人化推荐是否有用户画像证据，以及宏观、政策、行业、估值、盈利、技术、资金、情绪或历史阶段等与建议匹配的证据
- 多资产/多行业方向选择是否提供历史类似阶段、估值分位、盈利确定性、弹性、持续性和回撤等关键依据
- 深层资料问题是否意识到普通公开搜索可能不足，需要调研纪要、研报全文、iFind 类数据库或公司披露
- 是否区分一手证据、二手解读、通用概念材料和过时材料
- 是否优先使用与本题最相关的资料：消息面看最新催化，基金看持仓和排名，价值股看研报/财报/业绩预测，客户占比看调研纪要或交流纪要
- 若未找到重大消息、客户占比或隐含资产证据，是否明确说明来源限制和不确定性

常见失败模式：
- 搜了很多但没有关键政策、公告、调研纪要或最新新闻
- 用行业介绍替代具体标的证据
- 用普通搜索结果回答需要专业数据库的问题
- 工具返回了数据但模型误读或没有用到关键字段
- 思路很高级，但用户要求的关键数据没有给出来
- 直接给标的推荐，但缺少支持适配性和风险收益取舍的证据
- 用时间窗口外的小消息凑“最近资讯”，或用行业背景替代当前股价催化

## 边界说明

- 与 `recency_time_boundary` 的区分：本维度负责来源是否可信、充分、专业，不负责时间锚点是否正确。若来源权威但使用了过时数据，属于 `recency_time_boundary` 扣分而非本维度。
- 与 `tool_usage` 的区分：本维度评判最终答案的证据是否充分可信；`tool_usage` 评判链路中工具选择和调用策略是否正确。来源缺失可能是工具选择不当导致（`tool_usage` 扣分），也可能是工具正确但数据源本身不足（本维度扣分）。

## 适用性判断

- **relevant**：需要事实、数据、新闻、公告、研报、调研、行情或财务支撑。
- **supplementary**：纯分析框架或概念解释，但仍需基本可信来源。
- **not_applicable**：极少使用，仅当用户明确只要求主观写作或格式处理。
