# L1: `reasoning`

用于归因推荐推理、适当性判断、仓位设计或触发条件失败。

常见 L2：
- `suitability-logic-gap`：推荐理由成立，但没有证明适合该用户。
- `action-trigger-missing`：有方向判断但没有买卖、仓位、期限或触发条件。
- `allocation-framework-mismatch`：组合结构与用户资金、风险或目标不匹配。
- `comparison-without-tradeoff`：多资产或多方向比较没有取舍逻辑。
- `high-risk-advice-for-fragile-user`：对亏损/迷茫/低风险用户给高风险策略。

证据要求：
- 引用最终答案中的推荐、仓位或动作。
- 说明推理缺口如何导致建议不可执行或不适配。
