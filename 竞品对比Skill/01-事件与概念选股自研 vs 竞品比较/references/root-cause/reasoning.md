# `reasoning` — 推导投资逻辑

当系统投资逻辑错误或未能完成逻辑链时使用。

| L2 | 说明 | 典型受影响维度 |
|---|---|---|
| `no-event-abstraction` | 复述新闻但未提取真正的驱动因素或催化剂 | event_abstraction |
| `no-industry-chain` | 未能将事件映射到受益链条，未区分核心与边缘受益者 | industry_mapping |
| `no-ranking-criterion` | 列出股票但无优先级逻辑，或排序缺乏明确标准支撑 | ranking_judgment |
| `broken-causal-chain` | 缺少事件到价格路径的推理，停留在行业评论层面，或开头强收尾弱 | logic_closure |
| `purity-tiering-missing` | 未按受益纯度、业务占比、确定性、弹性、中军/小票等对标的分层，导致主次不明 | ranking_judgment, industry_mapping |
| `market-mechanism-misread` | 把事件炒作理解成单纯涨幅、资金流或行情指标，忽略事件贴合度、赚钱效应复制和题材发酵链路 | event_abstraction, ranking_judgment |
| `forced-analogy` | 为迎合对标问题强行凑相似公司，未解释商业模式、产业位置和壁垒差异 | industry_mapping, credibility_expression |
| `quant-link-missing` | 有数据但没有说明数据如何支撑受益、弹性、龙头地位或投资价值 | logic_closure, credibility_expression |
