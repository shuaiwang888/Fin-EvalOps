# L1：金融推理

用于解释错误前提检查、交易规则推理、口径定义或因果顺序问题。

L2：
- `premise_not_checked`：没有先检查用户问题能否成立。
- `ambiguity_not_decomposed`：没有把模糊变量拆成可回答的条件。
- `trading_rule_reasoning_error`：交易制度、权限、计息、税费或清算推理错误。
- `threshold_definition_weak`：阈值或口径定义不合理或不可复核。
- `causal_order_reversed`：先看行情结果再反推事件，因果顺序错。

典型证据：北交所权限、T+1、撤单时段、国债逆回购计息、净利润断层因果顺序。
