# `analysis_framework_fit` 市场分析框架匹配度

判断答案是否采用金融市场常用、用户可理解的分析框架，而不是冷门字段或表层模板。

关注点：
- 主力：同时考虑大资金流向、成交量价、龙虎榜、知名席位/游资、异常交易。
- 筹码集中度：股东户数变化、大股东持股、机构持仓、筹码分布、集中度趋势。
- 增长点：客户突破、市占率提升、新订单、新产品放量、新区域、新政策、调研纪要中的边际变化。
- 止盈位：技术压力/支撑、目标收益、回撤纪律、基本面催化兑现、仓位和持仓周期。
- 客户/供应链：公开披露、公告、年报、招股书、调研纪要、研报和产业链证据。
- 商品/期货比价：汇率、单位、合约、税费、基差、内外盘传导机制。

常见失败模式：
- 用"集中度 90"这类不常用字段回答筹码集中度，缺乏市场解释。
- 增长点回答成公司业务介绍，完全没有边际变化。
- 止盈位只给一个数字，没有投资逻辑。
- 主力问题只查资金流，不查龙虎榜或知名席位。

## 维度边界

- 本维度负责**框架选择是否正确**（是否采用市场常用、用户可理解的分析框架）。
- 框架之下增量信息是否充分由 `insight_extension` 负责。

## 适用性判断

- **relevant**: 任何诊断、解释、增长点、资金、筹码、止盈、客户、比价类问题。
- **supplementary**: 简单事实题，但需要判断用户是否有潜在诊断意图。
- **not_applicable**: 纯客观单点数据查询。
