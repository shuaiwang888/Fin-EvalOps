# `wrong_analysis_framework` 分析框架错误

上限：`55`

触发条件：
- 采用明显不符合市场习惯的诊断框架，导致答案虽有数据但用户难以使用。
- 主力问题只看单一资金流字段，遗漏龙虎榜/席位/游资等关键语义。
- 筹码集中度只引用冷门集中度字段，遗漏股东户数、大股东持股、机构持仓等常用框架。
- 增长点回答成存量业务介绍，未识别边际变化。
- 止盈位只给一个价格，无技术/基本面/仓位/风险收益逻辑。
- 商品/期货比价忽略单位、汇率、合约和基差，仍给出确定测算。

不触发情形：
- 框架基本正确但维度不够丰富；在 `analysis_framework_fit` 和 `insight_extension` 扣分。
