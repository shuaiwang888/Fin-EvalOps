# L1: `data_logic`

用于归因数据口径、计算、案例真实性或推演自洽性问题。

常见 L2：
- `calculation-method-error`：回撤、收益、利润、估值、合约盈亏等计算方法错误。
- `time-window-mismatch`：时间窗口或交易日范围错配。
- `unverifiable-or-false-case`：案例先例失实或无法核验。
- `mixed-comparison-basis`：把需求量、价值量、利润弹性等不同口径混用。
- `unsupported-probability-or-price`：概率、点位或价位判断缺少依据。

证据要求：
- 引用用户要求的口径或时间窗口。
- 引用最终答案中的错误数据、案例或推演。
