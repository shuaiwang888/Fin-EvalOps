# `tool_usage` 工具使用合理性

判断模型链路中的工具选择、工具输入、工具输出读取和证据转化是否支撑复合意图任务。

关注点：
- 是否为不同子任务选择合适工具：结构化金融数据用 FinQuery，新闻和舆论用 Search，网页深读用 AccessingFullText，历史验证和回测用 BackTest，复杂计算用 CodeInterpreter
- 工具输入是否包含正确时间窗口、标的、行业、比较对象和指标口径
- 是否按子任务顺序组织工具调用，避免查了很多但漏关键数据
- 是否正确解读工具输出，并把结果转化为综合结论

常见失败模式：
- 明确要求 48 小时/7 天新闻却没有按时间窗口检索
- 明确要求估值、利润、市场份额，却只做泛搜索
- 工具结果与最终答案不一致或未被使用
- 为复杂任务调用大量工具，但没有形成最终闭环

## 适用性判断

- **始终 relevant**，在链路诊断阶段评分。
