# FinQuery（金融查询工具）

功能：获取标的相关的各类金融数据，包括宏观数据、财务数据、行情数据、事件数据、交易数据、个人账户数据、自选股、个股看点、股票概念、技术形态、交易日开盘查询等，涉及股票、美股、港股、基金、指数、宏观、可转债、期货等多个领域。当问题未明确提及标的类型，默认按"股票"处理。

使用规范：
1. 根据单个或多个条件筛选股票时，输入为原始问句，用户问句中所有条件必须同时出现在一个 FinQuery 工具输入中，禁止自行修改条件，请直接按照原问句查询。
2. 诊股问题指标查询，且查询指标大于 5 个需要进行拆分，利用多个 FinQuery 工具进行并行查询。
3. 输入具体的标的和指标，查询对应标的的相关数据，支持连续时段、固定时段、指定时间点等明确时间查询。

注意事项：
1. 不支持直接查询抽象时间段的相关指标查询（如具体事件所指代时间，需要搜索才能获取具体的时间点）或需复杂逻辑推断的查询。
2. 不支持查询天气等非金融指标。
3. 工具输入时间是一个具体的、明确的时间范围。
4. 如果输入主体、指标、标的过多，则需要适当拆分，以提高查询成功率。
5. 由于上下文限制，金融查询结果只展示部分数据。
