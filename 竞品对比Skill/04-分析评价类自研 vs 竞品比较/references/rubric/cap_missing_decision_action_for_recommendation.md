# 封顶规则：`missing_decision_action_for_recommendation`

分数上限：`65`

当用户明确要求推荐、买卖、持有、割肉、加仓、仓位比例、方向取舍或具体标的，但最终答案没有给出可执行动作或触发条件时触发。

触发条件：
- 只有背景分析，没有回答“买什么、买多少、持有还是卖、是否加仓、选哪个方向”。
- 只说“可关注、谨慎、长期看好”，没有仓位、期限、优先级、入场/退出条件。
- 给了标的名称，但没有说明配置角色、仓位上限、观察条件和风险边界。
- 对复杂多子任务只回答市场风险或行业分析，漏掉用户最后要求的“结合我的风格推荐”。

不触发条件：
- 答案因信息不足不直接给单一确定动作，但提供清晰分层决策、观察条件、仓位框架和下一步信息需求。

根因优先映射：
- `composition.no-clear-conclusion`
- `intent.hidden-investment-need-missed`
- `reasoning.no-comparison-criterion`
